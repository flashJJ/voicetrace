# 文档中心

> 最后更新：2026-11-19

`docs/` 下的文档按用途分四个目录。新增文档时请放到对应目录，并更新本索引。

## 目录说明

| 目录 | 用途 | 典型内容 |
|---|---|---|
| `contest/` | 比赛相关 | 赛事规则、竞品调研、执行计划、试玩报告、报名帖、路演稿 |
| `guide/` | 项目指导 | 产品总览、技术架构、代码地图、数据模型、开发部署 |
| `development/` | 后续开发方案 | 路线图、技术债、待验证假设、赛后产品化 |
| `blog/` | 技术与项目分享 | 工程实录、设计取舍、可对外发布的文章 |

## 维护约定

- 新增文档必须在本索引登记
- 文档内引用其他文档时使用相对路径，避免移动后失效
- 涉及数字的结论标注日期，避免过期数据被当成现状
- 模拟数据必须显式标注「模拟」，不得写成真实用户证据
- 技术方案变更时，同步更新 `guide/` 对应章节
