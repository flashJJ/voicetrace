## 3. 产品规格（声迹 · 方言故事书）

### 3.1 命名与定位

| 项目 | 内容 |
|---|---|
| 中文名 | 声迹 |
| 副标题 | 方言故事书 |
| 一句话 | 把爷爷奶奶讲的故事，变成可以玩的方言互动书。 |
| 英文名 | VoiceTrail / Dialect Storybook |
| 目标用户 | 离乡年轻人、家庭、学校/社区文化教育者 |
| 核心价值 | 留住声音、听懂方言、分享故事 |

### 3.2 页面结构

| 页面 | 作用 | 关键元素 |
|---|---|---|
| 首页 | 3 分钟讲清价值 | 一句话、示例故事、立即体验、3 张截图 |
| 故事馆 | 浏览故事 | 3 个种子故事、方言标签、地图入口 |
| 故事详情 | 互动阅读 | 3 幕、选择、语音示例播放、字幕、注释 |
| 素材/故事库 | 选素材/建故事 | 资料库检索、选择素材、授权状态、转写（可选） |
| 故事编辑 | 校对/编排 | 文本校对、翻译、注释、分幕 |
| 分享卡 | 传播 | 海报/二维码/下载/分享 |
| 地图 | 声音地图 | 3 个 pin、故事卡片 |
| 关于/隐私 | 信任 | 授权说明、AI 标注、删除数据 |

### 3.3 数据模型（最小）

```text
Story: id, title, dialect, region, cover_url, summary, source_type, consent_status, created_at
Scene: id, story_id, order, text_dialect, text_mandarin, audio_url, image_url
Choice: id, scene_id, label, next_scene_id
Glossary: id, story_id, dialect_word, mandarin, note, audio_url
Recording: id, story_id, file_url, duration, consent, created_at
ShareCard: id, story_id, image_url, token, created_at
MapPin: id, story_id, lat, lng, place_name
```

### 3.4 故事引擎（最简）

- 用 JSON 描述 3 幕：

```json
{
  "title": "月光光",
  "dialect": "粤语",
  "scenes": [
    {
      "id": "s1",
      "text": "月光光，照地堂……",
      "audio": "/audio/s1.mp3",
      "image": "/img/s1.jpg",
      "choices": [
        { "label": "听阿婆讲下去", "next": "s2a" },
        { "label": "问阿婆这是什么意思", "next": "s2b" }
      ]
    }
  ]
}
```

- 不做复杂状态机；用 `next` 指向下一幕即可。
- 2 个结局：`s3a`、`s3b`。
- 每幕可播放语音示例/普通话辅助音；注释点击弹出。

### 3.5 音频与字幕

- 语音示例：浏览器语音/TTS，标注“AI 合成/示例”；真实录音为可选加分项。
- 辅助音：CosyVoice/平台 TTS，标注“AI 合成”。
- 字幕：方言原文 + 普通话翻译，可切换。
- 注释：方言词 → 普通话 → 文化解释（30 字内）。

### 3.6 分享卡

- 尺寸：1080×1440（竖版）。
- 内容：故事名、方言、地点、一句金句、二维码、声迹 logo。
- 技术：HTML canvas 或 satori + resvg；导出 PNG。
- 可选：15 秒视频（3 幕截图 + 语音示例 + 字幕）。

### 4.1 选 3 个故事（从资料库）

| 故事 | 资料库 ID | 类型 | 授权 | 备注 |
|---|---|---|---|---|
| 《月光光》 | `yue-rhyme-moonlight` | 童谣 | `traditional-public-domain` | 已有全文 + 方言词，适合做第一版 |
| 《五羊传说》 | `yue-legend-five-goats` | 传说 | `government-fact` | 有明确来源，适合做“城市起源”故事 |
| 《波罗鸡——靠黐》 | `yue-proverb-polo-chicken` | 歇后语 | `traditional-public-domain` | 有双关和文化背景，适合做轻喜剧 |
| （可选）真实家庭故事 | 待新增 | 真实故事 | 需授权 | 不作为前置条件；有素材再补 |

> 不要求人工录入。资料库已有 91 条素材，先选 3 条跑通；缺正文的篇目标 `needsResearch`，不要硬编。

### 4.2 素材使用与授权（无人工录音版）

- 优先使用 `traditional-public-domain` 和 `government-fact` 条目；`reference` 条目只作线索，正文需原创改写。
- 当前不做真人录音采集；语音示例用浏览器语音/TTS，明确标注“AI 合成/示例”。
- 如果后续补真实录音：再走授权、隐私说明、删除流程；真实录音是加分项，不是前置条件。
- 不在故事中暴露真实姓名、住址、电话；用“阿婆/外公”等称呼。
- 不直接使用影视/短视频/音乐平台的音频、截图、配乐。

### 4.3 版权、合规与黄金样品

- 传统童谣/民间故事：文本本身通常无版权，但**具体改编/录音/插画**有版权；用自己的话重写、自己生成/绘制。
- AI 生成图片/配音：遵守平台条款；标注“AI 生成/合成”。
- 地图：示意地图即可；如用 OpenStreetMap + MapLibre/Leaflet，保留 attribution。
- 中国语言资源保护工程等官方语料：**不直接抓取/商用**；仅参考，需要授权才能使用。
- 每条素材必须有 `source`；不确定授权时标 `reference` + `needsResearch`。
- 黄金样品（`web/data/corpus/golden-samples.json`）是 AI 输出的验收标尺：三幕数量、方言词、翻译、实体不幻觉。
