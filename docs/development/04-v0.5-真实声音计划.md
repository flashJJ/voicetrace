# v0.5 版本迭代计划：把真实声音留下来

## 1. 版本信息

| 项 | 内容 |
|---|---|
| 版本 | v0.5 |
| 分支 | `release/v0.5` |
| 起点 | v0.4（20 个故事、150 条素材、3 段真人样本、3-8 幕随机叙事） |
| 定位 | 产品能力：从「听故事」走到「录下我家的声音」 |
| 截止 | 2026-11-23 报名截止前完成 P0 |

## 2. 背景

v0.4 已经解决「故事怎么讲得不一样」，但核心承诺「留住声音」还停在展示层：
故事内播放仍是浏览器语音合成，真人录音只有 3 段公开样本。

v0.5 要补上最小可用闭环：

1. 用户能对着故事片段录音
2. 录音能保存、重录、校对文字
3. 故事里能听到「我家的版本」
4. 能把录音任务交给家人，一起补全

## 3. 目标与非目标

### 3.1 目标

- 浏览器内完成录音、试听、重录、删除，不需要账号
- 录音与「故事 + 场景」绑定，刷新后仍在
- 故事阅读页优先播放用户录音，没有录音时回退到语音合成
- 可编辑逐句转写文本，方便长辈校对
- 可导出「家庭录音任务包」，家人导入后补录，再合并
- 隐私说明清楚：默认只存在本机，不上传服务器

### 3.2 非目标

- 不接自动语音识别（ASR）
- 不做云端存储、家庭账号、实时协作
- 不做音频降噪、剪辑多轨
- 不改现有故事结构与生成器

## 4. 用户流程

### 4.1 录音

故事页 →「录下我家的版本」→ 选择场景 → 看粤语提示 → 录音 → 试听 → 保存。
保存时填：朗读者称呼（可选）、与故事的关系（可选）、是否同意本机保存。

### 4.2 校对

「我的声音档案」按故事分组，逐条显示：
场景标题、时长、录音时间、转写文本（可编辑）、播放、重录、删除。

### 4.3 播放

故事阅读页每个场景：
- 有我的录音：显示「播放我家的版本」，并在下方显示转写
- 没有录音：保持现有语音合成按钮

### 4.4 家庭任务包

档案页导出 `voicetrace-family-<日期>.json`：
包含故事 slug、场景 id、提示文本、已录数量，不含音频。
家人导入后看到待录清单，录完再导出带音频的包，由主用户合并。

## 5. 技术方案

### 5.1 录音

- `MediaRecorder`，优先 `audio/webm;codecs=opus`，Safari 回退 `audio/mp4`
- 单段上限 90 秒，超时自动停止
- 录音时显示波形（AnalyserNode，轻量 CSS 柱状）
- 麦克风权限拒绝、无设备、浏览器不支持三种错误分别提示

### 5.2 存储

IndexedDB 数据库 `voicetrace`，表 `recordings`：

| 字段 | 说明 |
|---|---|
| id | `storySlug:sceneId` 或时间戳 |
| storySlug / sceneId | 绑定位置 |
| blob | 音频 Blob |
| mime | 实际格式 |
| duration | 秒 |
| transcript | 可编辑文本 |
| speaker | 朗读者称呼 |
| relation | 与故事的关系 |
| consent | 是否同意本机保存 |
| createdAt / updatedAt | 时间 |

配额：单段 ≤ 8 MB，总量 ≤ 80 MB；超限提示先导出再清理。

### 5.3 模块划分

| 文件 | 职责 |
|---|---|
| `lib/recorder.js` | 媒体流、MediaRecorder、时长、错误映射 |
| `lib/recordings.js` | IndexedDB 增删改查、导出/导入、配额 |
| `hooks/useRecorder.js` | 录音状态机 |
| `app/record/page.js` | 录音棚 |
| `app/archive/page.js` | 我的声音档案、校对、任务包 |
| `components/SceneAudio.jsx` | 故事页播放用户录音 / 回退语音合成 |

### 5.4 静态导出兼容

全部逻辑在客户端，使用 `"use client"`；不新增 API。
静态站与服务端行为一致，录音只在本机。

### 5.5 隐私与边界

- 录音不自动上传；页面上明确写「只存在这台设备」
- 删除即从 IndexedDB 移除，不做软删除
- 导出文件含音频前再次确认
- 不采集声纹，不做身份识别

## 6. 优先级

### P0（报名前必须）

- 录音棚：录制、停止、试听、保存、重录
- 档案页：列表、播放、转写编辑、删除、导出单段
- 故事页播放用户录音，缺失时回退
- 隐私说明、权限错误处理、移动端适配

### P1（有余力）

- 家庭任务包导出/导入/合并
- 波形可视化
- 录音质量提示（太小、太长、静音）
- 「我家的声音卡」Canvas 分享图

### P2（赛后）

- 服务端对象存储与账号
- ASR 初稿 + 人工校对
- 多家庭成员实时协作

## 7. 三个 Sprint

### Sprint 1 · 录音与本地存储

- 建立 `release/v0.5`
- 实现 recorder、IndexedDB、录音棚页面
- 档案页最小列表与播放
- 验收：桌面 Chrome / Android 录音后刷新仍在

### Sprint 2 · 故事内播放与校对

- 故事页接入 `SceneAudio`
- 档案页转写编辑、重录、删除
- 移动端样式与错误提示
- 验收：录 3 段、改 1 段文字、故事内播放正确

### Sprint 3 · 家庭任务包与收口

- 任务包导出/导入/合并
- 隐私文案、关于页更新、导航入口
- 内容校验、双端构建、部署
- 验收：完整走通「录音 → 校对 → 故事播放 → 任务包」

## 8. 验收标准

- 支持的浏览器可完成录音，拒绝权限时有明确提示
- 录音刷新后仍可播放，删除后立即消失
- 每个场景最多一条「我的录音」，重录覆盖旧录音
- 故事页有录音时优先播放录音，没有时回退语音合成
- 档案页可编辑转写并持久化
- 导出文件可被再次导入，任务包不包含音频
- `check:content`、standalone、静态导出全部通过
- 线上 `/record`、`/archive`、故事页移动端可用

## 9. 风险

| 风险 | 应对 |
|---|---|
| iOS Safari 录音格式不同 | 运行时检测 mime，保存实际类型，播放用 Blob URL |
| IndexedDB 被隐私模式禁用 | 捕获错误，提示改用普通窗口或仅试听不保存 |
| 录音太长占空间 | 单段 90 秒上限 + 总量配额 + 导出后清理 |
| 赛前范围膨胀 | P1 可砍，P0 不依赖服务端 |
| 用户误解为已上传 | 页面固定文案 + 保存前同意勾选 |

- v0.5 完成后再合并 `main`，同时部署 GitHub Pages 与 Trae 服务端
- 服务端本次继续保留 20 个故事 / 150 条素材，不新增 API
- 部署后验证：`/record`、`/archive`、故事页录音回退、移动端视口
