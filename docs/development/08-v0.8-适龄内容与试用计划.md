# v0.8 版本迭代计划：适龄内容与真实试用

## 1. 版本信息

| 项 | 内容 |
|---|---|
| 版本 | v0.8 |
| 分支 | `release/v0.8` |
| 起点 | v0.7（儿童模式 + 学习闭环） |
| 定位 | 让儿童定位有独立内容池和真实试用反馈，随后冻结 |
| 状态 | 已发布（2026-11-19，真实亲子试用待补） |

## 2. 目标

- 儿童模式不再依赖成人故事，形成 8-10 个适龄故事的独立内容池
- 新增故事同时具备分级、词卡、小测、封面的完整配置
- 完成 1-2 次真实亲子/教师试用，记录问题并修复阻断项
- 版本冻结，进入材料统一重做阶段

## 3. 新增内容

### 3.1 五个适龄故事（暂定）

| 故事 | 来源 | 年龄 | 主题 |
|---|---|---|---|
| 氹氹转，菊花圆 | 粤语童谣 | 4-6 | 游戏、圆圈、集体 |
| 点虫虫 | 粤语童谣 | 4-6 | 昆虫、观察、亲子手指游戏 |
| 排排坐，食粉果 | 粤语童谣 | 4-6 | 分享、排队、食物 |
| 落雨大，水浸街 | 粤语童谣 | 4-6 | 下雨、街区记忆、安全 |
| 年廿八，洗邋遢 | 广府民俗 | 6-9 | 春节、家务、辞旧迎新 |

要求：

- 每个故事 5 幕左右，两个结局，选择具体、无恐怖元素
- 普通话翻译自然，方言词 3-5 个
- 配 900×675 封面，风格与现有故事一致
- 同步补齐 `learning.json` 词卡与 3 道小测

### 3.2 资料库补充

- 新增 10-15 条适龄素材：童谣、谜语、节日民俗
- 不与现有 150 条重复，儿童模式可用
- 标注 `kidSafe` 与年龄

### 3.3 可选真实录音

- 如能找到愿意授权的一两位家长/长辈，补 2-3 段童谣或短故事录音
- 只用于 `/about` 或儿童故事示例，需明确授权与署名
- 拿不到不阻塞发布

## 4. 试用方案

### 4.1 对象

- 1-2 个有 4-9 岁孩子的家庭
- 或 1 位幼儿园/社区粤语老师
- 不需要安装，直接用手机浏览器打开线上地址

### 4.2 试用任务

1. 从首页进入儿童模式
2. 选一个 4-6 故事，读完两幕
3. 录一段跟读，回放
4. 做 3 道小测，看小结
5. 家长查看录音、尝试删除
6. 退出儿童模式，确认成人功能还在

### 4.3 观察与记录

| 观察项 | 记录方式 |
|---|---|
| 孩子能否自己找到故事 | 是否卡在首页/导航 |
| 是否愿意开口录音 | 主动/需鼓励/拒绝 |
| 小测是否看得懂 | 读题困难、选项困惑 |
| 家长是否理解隐私 | 能否说出录音存在哪 |
| 阻断问题 | 打不开、录不了、按钮太小 |

试用记录写入 `docs/development/09-v0.8-试用记录.md`；可直接执行的招募、知情同意、观察表与问卷见
[`11-v0.8-真实试用执行包.md`](11-v0.8-真实试用执行包.md)。

### 4.4 成功标准

- 孩子能在少量提示下完成一个故事
- 至少一次主动录音或愿意回放
- 家长能独立找到删除入口
- 无阻断级问题；非阻断问题进入修复清单

## 5. 修复与冻结

### 5.1 修复优先级

- P0：打不开、录音失败、儿童模式串到成人内容、隐私说明错误
- P1：按钮太小、文案难懂、进度丢失
- P2：视觉细节、动画、非核心提示

### 5.2 冻结检查

- [x] 儿童池至少 8 个故事，全部有分级、词卡、小测、封面（实际 14 个）
- [x] 内容校验、standalone、静态导出通过
- [x] 双端部署成功
- [x] 儿童/成人两条主路径回归
- [x] 试用阻断问题清零（脚本自测，真实试用待补）
- [x] 版本号、README、路线图更新
- [x] 打 tag `v0.8.0`
- [x] 移交材料收尾清单（[`10-v0.8-材料收尾清单.md`](10-v0.8-材料收尾清单.md)）

## 6. 优先级

### P0（必须）

- 5 个新故事与封面
- 新故事的分级、词卡、小测
- 10-15 条适龄素材
- 1-2 次试用与阻断问题修复
- 冻结与部署

### P1（有余力）

- 2-3 段授权真人录音
- 儿童故事合集页的推荐顺序
- 家长页的试用反馈入口

### P2（本版不做）

- 多方言
- 课堂管理
- 账号与云端同步
- 比赛材料重做（收尾阶段统一做）

## 7. 三个 Sprint

### Sprint 1 · 故事与素材

- 写 5 个故事、封面、分级字段
- 写词卡与小测
- 补 10-15 条适龄素材
- 验收：儿童池 8-10 个故事全部可读

### Sprint 2 · 试用与修复

- 邀请 1-2 个家庭/老师试用
- 记录问题、按 P0/P1 修复
- 验收：无阻断问题，试用记录完成

### Sprint 3 · 冻结与交付

- 全量回归、双端部署、打 tag
- 更新 README 与路线图
- 输出材料收尾清单
- 验收：版本冻结，材料阶段可以开始

## 8. 验收标准

- 儿童模式有 8-10 个独立适龄故事，不依赖鬼故事/野史
- 每个新故事有封面、分级、词卡、3 道小测
- 至少一次真实试用，有记录、有修复
- 儿童与成人路径均正常
- 双端构建与部署通过
- `v0.8.0` tag 与材料清单就绪

## 9. 风险

| 风险 | 应对 |
|---|---|
| 5 个故事写不完 | 先保 3 个，儿童池达到 8 个即可 |
| 试用对象找不到 | 老师/朋友远程试用，按脚本自测并记录 |
| 新故事与旧素材重复 | 写前先查 150 条资料库，校验脚本查重 |
| 试用暴露大问题 | 只修阻断项，非阻断进入赛后清单 |
| 材料时间被挤压 | v0.8 冻结后不再加功能，全部转入材料 |
