# v0.7 版本迭代计划：听、跟读、认词、小测

## 1. 版本信息

| 项 | 内容 |
|---|---|
| 版本 | v0.7 |
| 分支 | `release/v0.7` |
| 起点 | v0.6（儿童模式、内容分级） |
| 定位 | 把儿童模式从「能读」推进到「有学习闭环」 |
| 状态 | 开发中（release/v0.7，2026-11-19 启动） |

## 2. 目标

- 每个适龄故事都能走完「听 → 跟读 → 认词 → 小测 → 小结」
- 跟读复用现有录音能力，不引入发音评分
- 学习进度只存本机，家长可以看到，也可以一键清除
- 不录音也能完成阅读和测验，录音始终是可选增强

## 3. 用户流程

1. 孩子听一段示例语音
2. 点「跟读」，录下自己的版本，回放对比
3. 点开本幕 1-2 个关键词卡，看意思和例句
4. 读完后做 3 道理解小测，答对给鼓励
5. 小结页显示：读了几幕、录了几段、认识几个词、答对几题
6. 家长可以查看或清除这份学习记录

## 4. 数据设计

### 4.1 学习内容

新增 `web/data/kids/learning.json`，按故事组织：

```json
{
  "moonlight": {
    "sceneWords": {
      "moonlight-1": [
        { "term": "月光光", "meaning": "月光很亮", "example": "月光光照地堂。" }
      ]
    },
    "quiz": [
      {
        "question": "阿婆教“我”唱的是什么？",
        "options": ["童谣", "粤剧", "山歌"],
        "answer": 0,
        "hint": "故事一开始就在唱。"
      }
    ]
  }
}
```

要求：

- 每个儿童故事至少 3 个关键词、3 道小测
- 关键词必须来自故事原文或 glossary
- 小测只考故事内容，不考生僻知识

### 4.2 本机进度

新增 `lib/kid-progress.js`，用 localStorage 存：

```json
{
  "moonlight": {
    "visited": ["moonlight-1", "moonlight-2a"],
    "recorded": ["moonlight-1"],
    "words": ["月光光"],
    "quiz": { "answers": [0, 1, 2], "correct": 2 },
    "updatedAt": 0
  }
}
```

- 不上传、不做账号
- 提供 `clearKidProgress(slug)` 与 `clearAllKidProgress()`
- 录音本身仍在 IndexedDB，进度只存 id 与结果

## 5. 页面与交互

| 位置 | 功能 |
|---|---|
| 儿童阅读页 | 每幕「跟读」按钮、关键词卡、进度点 |
| 儿童阅读页结局 | 「做 3 道小测」入口 |
| 小测页 `/kids/[slug]/quiz` | 3 题、即时反馈、结果 |
| 小结页 `/kids/[slug]/summary` | 阅读/录音/词语/答题统计 |
| 家长页 `/kids/parent` | 查看各故事进度、清除记录 |

交互原则：

- 大按钮、短文案、一次只做一件事
- 答错不扣分，给提示后可重试
- 跟读录音默认不自动播放，需孩子或家长点击
- 随时可以跳过录音和测验

## 6. 技术方案

- 复用 `useRecorder`、`recordings.js`、`SceneAudio`
- 新增 `components/KidReadAlong.jsx`：录音、回放、重录
- 新增 `components/KidWordCard.jsx`：关键词卡
- 新增 `components/KidQuiz.jsx`：小测与结果
- 新增 `lib/kid-progress.js`：进度读写
- 小测与小结为纯客户端页面，静态导出可用
- 儿童阅读页在 v0.6 基础上增加学习区，不影响成人 Reader

## 7. 优先级

### P0（必须）

- 5-8 个核心儿童故事的学习内容（词卡 + 3 题小测）
- 每幕跟读录音与回放
- 小测与结果页
- 小结统计
- 本机进度保存与清除
- 成人模式回归

### P1（有余力）

- 家长页查看进度
- 词语卡「已认识」标记
- 读完一个故事后的连续推荐
- 录音对比：示例语音 / 我家的版本切换

### P2（本版不做）

- 自动发音评分
- 排名、积分、打卡
- 教师端与班级管理

## 8. 三个 Sprint

### Sprint 1 · 学习内容与词卡

- 编写 5-8 个故事的学习 JSON
- 儿童阅读页接入关键词卡
- 校验脚本检查词条与题目结构
- 验收：每个核心故事至少 3 词、3 题

### Sprint 2 · 跟读与小测

- 每幕跟读录音、回放、重录
- 小测页、即时反馈、结果
- 验收：一个故事完整走完四步

### Sprint 3 · 小结、家长页与回归

- 小结统计、进度保存与清除
- 家长页
- 移动端与成人模式回归
- 双端构建与部署

## 9. 验收标准

- 一个儿童故事可以完成「听 → 跟读 → 认词 → 小测 → 小结」
- 不录音也能完成阅读和小测
- 刷新后进度仍在，可一键清除
- 儿童模式外的功能不受影响
- 内容校验、standalone、静态导出通过
- 线上 `/kids/[slug]/quiz`、`/summary` 可访问

## 10. 风险

| 风险 | 应对 |
|---|---|
| 内容编写量大 | 先做 5 个核心故事，其余 v0.8 补 |
| 学习闭环变成考试 | 小测 3 题、答错给提示、不排名 |
| 录音步骤打断阅读 | 跟读是可跳过按钮，不强制 |
| 进度数据分散 | 统一用 `kid-progress`，录音仍由 recordings 管理 |
| 家长页涉及隐私 | 只读本机数据，提供清除入口 |

## 11. 本版决定（开发前确认结果）

1. 第一批覆盖现有 9 个儿童故事，词卡与小测一次补齐。
2. 小测放独立页面 `/kids/[slug]/quiz`，结局页提供入口。
3. 跟读为练习录音：只在当前页面录制与回放，不写入声音档案；要保存正式版本走 `/kids/record`。
4. 家长页本版必须，只读本机进度，支持单个故事与全部清除。
