# 13 · v0.9 国际化交付

> 状态：已完成
>
> 周期：2026-11-20
>
> 目标：面向香港与海外华侨家庭，提供简体中文 / 繁体中文 / English 三语切换

## 1. 背景与范围

真实家庭试用暂停，产品先在仿真内容上打磨，并把受众从内地粤语家庭扩展到香港与海外华侨家庭。本版本只做国际化，不新增故事、不改叙事结构。

范围内：

- 全站语言切换：`zh`（默认）/ `zh-HK` / `en`，同一路由，不拆子路径
- 25 个故事的英文覆盖：标题、副标题、金句、简介、方言/类型/时长、每一幕标题与正文、结局、选项、方言词注释
- 14 个儿童故事的英文词卡与三道小测
- 全站界面文案英文化：首页、故事馆、阅读器、儿童线、录音棚、声音档案、资料库、声音地图、AI 工坊、演示页、关于页
- 繁体中文：界面与故事文案统一由 `opencc-js` 做简转繁，避免手工维护第二套文案

不做：

- 不翻译资料库 164 条素材正文与 AI 演示故事正文；英文界面明确标注「原始资料为中文」
- 不做语言子路径（`/en/...`）与 SEO hreflang，留到有真实海外流量后再评估
- 不接入第三方翻译 API，所有英文为人工/模型生成后落盘到仓库

## 2. 实现方案

| 模块 | 文件 | 说明 |
|---|---|---|
| 语言状态 | `web/components/LocaleProvider.jsx` | Context 提供 `locale / setLocale / localize / pick / ready`；偏好写入 `voicetrace:locale`；首次访问按浏览器语言判断 |
| 繁中转换 | `opencc-js` | 仅在 `zh-HK` 时懒加载 `cn → hk` 转换器，失败时回退简体 |
| 故事英文覆盖 | `web/data/i18n/*.json` | 按故事子集拆成 5 个文件，共 25 个 slug；`web/lib/i18n-content.js` 负责合并与本地化 |
| 学习内容英文 | `web/data/i18n/learning-en.json` | 14 个儿童故事的词卡与小测，按数组下标对齐原文，避免改题型 |
| 页面文案 | 各页面 `COPY = { zh, en }` | `pick(COPY)` 选语言并自动转繁；动态文案写成函数，句内中文用 `localize()` |
| 分享卡 | `web/components/ShareCard.jsx` | Canvas 内的品牌、印章、来源说明随语言切换 |
| 语音/录音错误 | `hooks/useRecorder.js`、`useSpeech.js`、`useSpeechPlayback.js` | 用 ref 持有当前语言文案，避免切换语言导致回调重建 |

约定：

- 数据内容（故事正文里的粤语原文、用户录音、语料标题与摘要）不翻译；界面文案才翻译。
- 默认服务端渲染为简体，语言偏好在客户端恢复，避免静态导出时按语言拆页。
- 新加页面时，界面文案必须放进 `COPY.zh / COPY.en`，不要直接写中文。

## 3. 验收

| 检查 | 结果 |
|---|---|
| `npm run build`（standalone） | 通过，84 个页面 |
| `node scripts/build-static.mjs` + `npm run test:static` | 通过，83 个静态页面；新增语言开关与英文覆盖检查 |
| `npm run check:content` | 通过：25 个故事 / 14 个儿童故事 / 164 条素材 / 8 个黄金样品 |
| `npm test` | 27 项通过；新增英文覆盖完整性测试（25 个故事、14 个儿童故事） |
| 浏览器验证 | 简 → 繁切换正常（聲跡 / 故事館）；EN 下首页、儿童故事页、录音棚、声音档案均为英文，无控制台报错 |

英文覆盖测试检查：每个故事的元信息、每一幕标题与正文、结局、选项数量、方言词释义，以及每个儿童故事的词卡数量与例句、小测题数与选项数量。

## 4. 已知限制

- 资料库语料、AI 工坊生成结果、演示故事正文仍为中文；英文界面有说明，后续可按需增量翻译。
- 浏览器内置语音（TTS）不保证有粤语声音；无粤语时会退化为中文示例，界面会提示。
- 繁体转换是字符级简转繁，个别粤语用字可能需要人工校对；后续可维护术语表。
- 页面 `<title>` 与分享元信息仍以简体中文为主，未做多语言 SEO。

## 5. 下一步

1. v0.10 作为国际化后的最后一次功能迭代：只做香港/华侨家庭最需要的体验修正与内容补丁，不再扩系统。
2. 之后进入材料阶段：按新定位重做产品说明、路演页与演示视频，明确「仿真内容、未做真实试用」。
3. 若海外流量验证成立，再评估 `/en` 子路径、hreflang 与资料库英文摘要。
