# 后续开发方案（固定归档目录）

本目录用于集中存放**尚未完成或计划中的开发方案**。所有后续迭代计划、技术债、待验证假设都写在这里，不再散落在根目录或聊天记录中。

## 归档规范

1. 一个方案一个文件，命名 `NN-方案名.md`，序号递增。
2. 已完成或已放弃的方案不删除，在文件顶部标注状态：`进行中` / `已完成` / `已放弃`。
3. 方案里必须写清楚：目标、范围、验收标准、风险、不做什么。
4. 功能开发前先在本目录登记，再动代码；完成后把结论回写到方案文件。
5. 与比赛直接相关的排期仍以 `docs/contest/13-参赛加码迭代计划.md` 为准，本目录负责比赛之后和维护性工作。
