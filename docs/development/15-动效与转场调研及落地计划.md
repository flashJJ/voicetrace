# 15 · 入场动画与交互转场：调研、选型与落地计划

> 状态：进行中（首页古风入场、毛笔光标、点击墨点已上线；路由转场与滚动入场待实施）
> 目标版本：v0.13
> 结论先行：以浏览器原生 **View Transitions + CSS/WAAPI** 为底座，**Motion 只做按需增强**；P0 不引入 GSAP、Lottie、Rive、Lenis。

## 1. 目标与约束

### 目标

1. 首页一支 1.2 秒以内的品牌入场动画（印章 + 声波 + 标题）。
2. 页面之间的转场：首页 → 故事馆 → 阅读器、成人线 ↔ 儿童线、列表 → 详情。
3. 滚动入场与列表微动效，让长页面有节奏，但不拖慢。
4. 所有动效可降级、可关闭，不影响内容与操作。

### 硬约束

| 约束 | 说明 |
|---|---|
| 技术栈 | Next.js 16.4.6 + React 19.3.1，App Router；`next build` standalone + `build-static.mjs` 静态导出双构建 |
| 静态导出 | GitHub Pages 是纯静态；动效不得依赖服务端 |
| 离线 | PWA 离线打开读过的页面，动效资源必须随包缓存 |
| 设备 | 香港与海外华侨家庭，中低端 Android / 旧 iPhone 占比不低 |
| 无障碍 | 已有全局 `prefers-reduced-motion` 降级（globals.css），必须延续 |
| 三语 | 简 / 繁 / 英文案长度差异大，动效不能依赖固定文本宽度 |
| 演示一致 | 3 分钟演示视频与线上一致；动效上线后需重录 |

## 2. 现状盘点

- 已有：`@keyframes rise`（0.7s，三档延迟 `fade-in` / `fade-in-delay` / `fade-in-delay-2`，用于首页 hero）；`studio-pulse`、`recorder-pulse` 两个循环脉冲。
- 已有：两处 `prefers-reduced-motion` 降级，一处把动画/过渡压到 0.001ms，一处关闭 `scroll-behavior`。
- 没有：路由转场、滚动入场、列表增删动画、统一的时长/缓动 token。
- 页面：`/`、`/stories`、`/stories/[slug]`、`/kids`、`/kids/[slug]`、`/kids/parent`、`/record`、`/archive`、`/map`、`/library`、`/studio`、`/demo`、`/about`。

## 3. 候选方案对比

> 体积均为 min+gzip 量级，来源见文末参考；不同打包方式差异较大，按同一功能对比。

| 方案 | 许可 | 体积 | React/Next 适配 | 能做什么 | 风险 | 结论 |
|---|---|---|---|---|---|---|
| 浏览器原生 View Transitions | Web 标准 | 0 KB | React 19.3 `<ViewTransition>`、Next `<Link transitionTypes>` 原生支持 | 路由级共享元素、淡入淡出、方向转场 | 旧 WebView 不支持，需要渐进增强 | **P0 采用** |
| CSS 动画 / WAAPI | Web 标准 | 0 KB | 无依赖 | 入场、hover、按压、脉冲、进度 | 复杂时间轴要手写 | **P0 主力** |
| Motion for React（`motion/react`） | MIT | mini 2.6–4.7 KB；`animate` 18 KB；React 完整约 31 KB（LazyMotion）～50 KB | 官方支持 React 19 | 弹簧、手势、`AnimatePresence`、布局动画 | 包体与运行时成本 | **P1 按需**，预算 ≤30 KB |
| GSAP 3.13+ | 闭源，Webflow 收购后免费（含原付费插件） | core 约 23–27 KB，带 ScrollTrigger 约 44 KB | 可用，但非 React 原生 | 强时间轴、ScrollTrigger、SVG | 闭源、体积大、许可禁止用于竞品工具 | 不采用 |
| anime.js v4 | MIT | 完整约 24.5 KB，可模块化 | 命令式，需自己包一层 | 时间轴、SVG、拖拽、滚动观察 | React 生命周期要手动管理 | 备选，不采用 |
| React Spring | MIT | 中等（约 20 KB 量级） | React 原生 | 物理弹簧 | API 心智与包体，对本项目收益低 | 不采用 |
| AutoAnimate | MIT | 约 3.5 KB | `useAutoAnimate` 一行接入 | 列表增删、排序过渡 | 只解决列表场景 | 备选（若列表改动变多再引入） |
| Lenis | MIT | <4 KB | 框架无关 | 平滑滚动 | 接管滚动，低端机与可访问性风险 | 不采用（保留原生滚动） |
| Lottie 运行时 | Apache-2.0 | 约 60 KB gzip | 有 React 封装 | 设计师导出的矢量动画 | 需要设计资产；JSON 体积大 | 不采用（P0） |
| Rive 运行时 | 免费/商业分层 | 约 200 KB gzip（WASM+JS） | 有 React 封装 | 交互式角色动画 | WASM 体积、离线缓存成本 | 不采用 |
| CSS scroll-driven animations | Web 标准 | 0 KB | 无依赖 | 纯 CSS 滚动叙事 | 2026-10 才 Baseline；Safari 26 / Firefox 159 起，旧 iOS 需降级 | 可选（长文页，@supports 内） |
| Magic UI / React Bits / Aceternity UI | 多为 MIT，Aceternity 免费+付费 | 复制片段 | 复制到项目 | 动效组件灵感与现成片段 | 风格重于内容，易“炫技” | 只做参考，不整体引入 |

## 4. 选型结论

| 层级 | 用途 | 方案 | 新增 JS |
|---|---|---|---|
| L0 | 品牌入场 | CSS keyframes + 内联 SVG path 描边 + WAAPI | 0 KB |
| L1 | 路由转场 | React `<ViewTransition>` + `next/link transitionTypes` + CSS | 0 KB |
| L2 | 滚动入场 | `IntersectionObserver` + `.reveal` class（一次性） | ~0.5 KB |
| L3 | 微交互 | CSS transition / WAAPI | 0 KB |
| L4 | 复杂交互（P1） | Motion `m` + `LazyMotion`，只在词卡/分享卡需要时加载 | ≤30 KB（懒加载） |

**明确不做**

- 不做全屏 Splash / 加载遮罩：会把可交互时间推迟 1 秒以上，也破坏 PWA 直开体验。
- 不做全局平滑滚动劫持（Lenis）：地铁、低端机上收益低，且与 `scroll-behavior`、锚点、读屏冲突。
- 不为动效引入设计工具链（Lottie / Rive）：当前没有设计师产出的 `.json` / `.riv` 资产，运行时成本换不来内容收益。
- 不在儿童线做大幅位移、闪烁、连续循环动画：儿童页只保留 ≤200ms 的反馈动效。

## 5. 入场动画分镜（首页）

### 时间轴（总 1.2s，之后完全可交互）

| 时间 | 元素 | 动作 | 缓动 |
|---|---|---|---|
| 0–250ms | 纸纹背景 | 透明度 0 → 1 | `ease-out` |
| 120–620ms | 红色印章「声」 | `scale 1.16 → 1`、`rotate -3° → 0`、`opacity 0 → 1` | `cubic-bezier(0.22,1,0.36,1)` |
| 200–760ms | 标题 | `translateY 18px → 0` + 淡入 | 同上 |
| 320–820ms | 副标题 | `translateY 12px → 0`，延迟 80ms | 同上 |
| 420–1000ms | 声波线（内联 SVG） | `stroke-dashoffset` 从全长到 0 | `ease-in-out` |
| 620–1100ms | CTA 与首屏卡片 | 错峰 `rise`，每项 +60ms，最多 4 项 | `ease-out` |

### 规则

- 只用 `transform` / `opacity` / `stroke-dashoffset`，不动布局，CLS 保持 0。
- 首屏 LCP 元素（h1、封面）正常渲染，动画只是叠加，不延迟绘制。
- 动画期间按钮在 300ms 后即可点击；不做指针拦截。
- 每个会话只播一次（`sessionStorage` 标记），二次进入直接终态。
- `prefers-reduced-motion: reduce` 时全部 `animation: none`，直接终态。
- 声波 SVG 内联，控制在 3 KB 以内，随 HTML 缓存，离线可用。

### 代码骨架

```css
:root {
  --ease-out: cubic-bezier(0.22, 1, 0.36, 1);
  --dur-fast: 120ms;
  --dur-base: 200ms;
  --dur-slow: 320ms;
  --intro-seal: 620ms;
}

@keyframes seal-drop {
  from { opacity: 0; transform: scale(1.16) rotate(-3deg); }
  to   { opacity: 1; transform: scale(1) rotate(0); }
}

.hero-seal { animation: seal-drop var(--intro-seal) var(--ease-out) 120ms both; }

@media (prefers-reduced-motion: reduce) {
  .hero-seal, .hero-title, .hero-sub, .hero-wave { animation: none !important; }
}
```

## 6. 路由转场设计

### 三种类型

| 类型 | 场景 | 效果 | 时长 |
|---|---|---|---|
| forward | 列表 → 详情、首页 → 故事馆 | 详情内容淡入 + 封面共享元素放大 | 220ms |
| back | 详情 → 列表 | 反向缩小 + 列表淡入 | 200ms |
| tab | 成人线 ↔ 儿童线、简繁英切换 | 纯淡入淡出，不做位移 | 160ms |

### 实现要点

1. 在 `app/layout.js` 用 `<ViewTransition>` 包裹 `<main>{children}</main>`，由 React 19.3 接管快照。
2. 用 `next/link` 的 `transitionTypes={['to-story']}` 标记方向（Next 16.4 已支持，本地 `node_modules` 已确认）。
3. 共享元素：被点击的封面在导航前设置 `style.viewTransitionName = 'story-cover'`，详情页同名；同一时刻页面上只能有一个同名元素。
4. 无 View Transitions 的浏览器（旧 WebView、部分国产内核）自动退化为即时跳转，不引入 polyfill。
5. `prefers-reduced-motion` 下关闭 `::view-transition-*` 动画，保留内容切换。

```jsx
// 列表卡片：只给当前点击的那张卡设置共享名
<Link
  href={`/stories/${story.slug}`}
  transitionTypes={['to-story']}
  onClick={() => { document.documentElement.style.setProperty('--vt-cover', story.slug); }}
>
```

```css
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: var(--dur-base);
  animation-timing-function: var(--ease-out);
}

@media (prefers-reduced-motion: reduce) {
  ::view-transition-group(*),
  ::view-transition-old(*),
  ::view-transition-new(*) {
    animation-duration: 0.001ms !important;
  }
}
```

> 注意：`view-transition-name` 冲突会让浏览器退回整页快照，所以只对“当前点击项”动态命名，列表默认不命名。

## 8. 落地计划

### P0：基础设施 + 入场 + 路由转场

1. `app/globals.css`：补时长/缓动 token、`rise` 复用、View Transition 规则、`prefers-reduced-motion` 段。
2. 新增 `components/HeroIntro.jsx`：只用于首页 hero，内联 SVG 声波；会话级播放一次。
3. 新增 `components/Reveal.jsx`：`IntersectionObserver` 一次性添加 `.is-visible`，支持 `--reveal-delay`。
4. `app/layout.js`：`<ViewTransition>` 包裹 `main`。
5. 新增 `components/TransitionLink.jsx`：封装 `transitionTypes`，列表与导航改用。
6. 故事卡片封面共享元素命名；详情页同名。
7. 验收：三语截图、`prefers-reduced-motion` 截图、静态导出构建、PWA 离线打开、双端部署。
8. 重录 3 分钟演示视频（与线上动效一致）。

### P1：滚动入场 + 微交互

1. 首页各 section 接 `.reveal`，每屏最多 6 项、延迟 ≤60ms。
2. 故事馆 28 张卡片按行错峰，滚动到视口才播，避免首屏一次性动画。
3. 词卡翻面、答题反馈、分享卡、小结数字按第 7 节接入。
4. 儿童页限制：只用 ≤200ms 的反馈动效，不做视差与连续循环。

### P2：可选增强（不做默认依赖）

- 需要弹簧/手势/布局动画时再引入 Motion：只在对应组件里 `dynamic import`，预算 ≤30 KB。
- 长文故事页可尝试 CSS scroll-driven（`@supports (animation-timeline: view())`），不支持则保持静态。
- 若未来有设计师产出 `.riv` 角色动画，再单独立项评估 Rive，不进入本计划。

## 9. 验收标准

- P0 新增 JS ≤10 KB（实际目标 0.5 KB，仅 IntersectionObserver）；P1 若引入 Motion，懒加载 ≤30 KB。
- LCP 相对当前退化 ≤100ms（4G + 4× CPU 限速）；INP <200ms；CLS = 0。
- 动画帧率：中端机 DevTools 4× CPU 限速下保持 60fps，掉帧不超过 2 帧。
- `prefers-reduced-motion: reduce`：0 位移、0 循环、直接终态，功能不受影响。
- 三语、离线、GitHub Pages 子路径与 Trae 根路径表现一致。
- 旧 WebView：无转场但页面可用；不出现白屏或整页错位。
- 一键关闭：`html[data-motion="off"]` 时所有动效禁用，便于回滚与排障。

## 10. 风险与回滚

| 风险 | 处理 |
|---|---|
| 旧 WebView 不支持 View Transitions | 渐进增强，自动退化为无动画跳转，不 polyfill |
| `view-transition-name` 冲突导致整页快照 | 只给当前点击项命名，列表默认不命名，测试覆盖 |
| 入场动画影响 LCP / 可点击 | 只动 transform/opacity，300ms 后按钮可点，1.2s 内结束 |
| 儿童页过度刺激 | 儿童线只保留 ≤200ms 反馈动效 |
| 动效导致录像与线上不一致 | 动效上线后立即重录演示视频与截图 |
| 需要回滚 | 移除 `data-motion="on"` 或删除 CSS 段，入场组件下线即可，无数据影响 |

## 11. 不做什么

- 不做全屏开场遮罩、不做延时加载动画。
- 不做鼠标跟随、粒子、3D 场景等重效果。
- 不为动效新增后端接口或第三方 CDN 资源。
- 不用动效替代信息层级：内容结构仍然靠排版与留白。

## 13. 2026-11-21 实施记录：古风电影版

### 已上线

- **首页入场 2.7s**：人像慢推 → 「声迹」双字书写 → 竖排对联《趁还会唱，把乡音留下来》→ 朱砂印章落印（带墨晕涟漪）→ 墨晕收束回印章并露出首页。
- **播放规则**：每个会话一次；`?intro=1` 可强制重播；点击 / 任意按键 / 滚轮 / 触摸立即跳过；`prefers-reduced-motion` 直接跳过。
- **首屏防闪**：`<head>` 内联脚本在首次绘制前判断 `sessionStorage` 并挂 `data-intro`，CSS 幕布兜底；hero 的 `rise` 动画在入场期间暂停，退场时交叉淡入。
- **毛笔光标**：`public/cursor/brush.png` 与 `brush-link.png`，仅在 `(pointer: fine)` 生效；输入框保持文本光标；链接与按钮用带朱砂点的笔锋。
- **点击墨点（修订版）**：不再使用多边形墨点（会像玻璃碎片），改为预渲染的柔边墨团贴图：1 个主墨团 + 1 层洇开外晕 + 3-5 个圆润墨点，`mix-blend-mode: multiply` 与纸面混色，760-900ms 线性淡出；约 12% 概率出现一点朱砂；输入框与 `data-no-ink` 区域不触发；DPR 上限 2；`reduced-motion` 下关闭。
- **文件**：`web/components/CinematicIntro.jsx`、`web/components/InkEffects.jsx`、`web/public/cursor/*`、`web/app/globals.css`、`web/app/layout.js`、`web/app/page.js`。
