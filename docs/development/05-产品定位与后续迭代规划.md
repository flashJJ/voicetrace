# 产品定位与后续迭代规划（记录）

> 记录时间：2026-11-19
> 当前基线：v0.5.1（20 个故事、150 条素材、本地录音棚、自动转写、声音档案、家庭任务包、录音联动）
> 状态：v0.6 / v0.7 / v0.8 已完成并发布；2026-11-20 定位拍板为「双入口」。

## 0. 定位决定（2026-11-20）

**决定：双入口。**

- 保留「家庭声音故事书」品牌与成人内容，不删除鬼故事、野史与家庭录音。
- 儿童模式作为第二条主线，拥有独立内容池与学习闭环，不依赖成人故事。
- 对外材料同时讲两件事：大人留住声音，孩子学会开口。
- 收尾材料按双入口重做，报名类别保持「游戏娱乐 / 文化体验」，可兼报学习生活。

## 1. 本次记录的三个决定

1. **定位候选**：把产品往「儿童粤语启蒙」方向考虑，但先做儿童模式验证，不立即替换现有「家庭声音故事书」定位。
2. **材料延后**：现有产品说明 PDF、PPT、3 分钟演示视频、比赛文档与截图已落后于 v0.3-v0.5.1，暂不逐份修补，等版本稳定后统一重做。
3. **迭代节奏**：比赛截止前再做 2-3 个版本，把功能补完整，然后集中做材料、演示与报名收尾；11-23 前仍可改动。

## 2. 定位评估：儿童粤语启蒙

### 2.1 为什么可能成立

- 现有能力天然贴合亲子场景：故事、普通话对照、方言词注释、跟读录音、声音档案。
- 录音闭环可以变成「跟读练习」：孩子录、家长听、逐句校对，不需要额外硬件。
- 本地优先、无账号、录音不上传，对儿童产品是明显优势。
- 20 个故事可以按年龄和难度重新分级，形成「听 → 说 → 认词 → 再讲」的轻学习路径。
- 家长比孩子更容易为「方言传承 + 陪伴」付费，教育定位也更容易解释价值。

### 2.2 需要正视的冲突

- 现有内容偏成人：鬼故事模式、野史里的地主/官府/灵异元素不适合低龄儿童。
- 「故事书」不等于「教育产品」：需要明确的学习目标、难度分级和可验证的练习，而不是只加一个儿童皮肤。
- 现有比赛类别是「游戏娱乐 / 文化体验」；若正式改为教育产品，需要确认报名类别、评审口径是否受影响。
- 儿童产品对安全、隐私、家长同意的要求更高；AI 生成内容不能直接暴露给孩子。
- 旧 PPT、PDF、演示视频都按「家庭故事书」叙事制作，定位切换后需要整体重做，而不是改几页。

### 2.3 候选定位表述（先不写进首页）

> 给 4-8 岁孩子和家长的粤语启蒙互动故事书：听一段故事，跟读一句粤语，认识一个方言词，把家里的声音变成教材。

备选范围待定：

- 年龄：4-6 岁亲子共读，或 6-9 岁独立跟读
- 场景：家庭亲子共读为主，还是幼儿园/社区课堂
- 目标：听懂、敢开口、认方言词，还是能复述故事
- 粤语基础：零基础家庭，还是家里本来讲粤语、孩子只会听不会说

### 2.4 定位决策门

不在这份文档里拍板。等 v0.6 儿童模式跑通后，用三个问题决定是否正式切换：

1. 儿童模式是否能在不破坏现有成人内容的前提下独立成立？
2. 跟读录音是否能形成可展示的学习闭环，而不是只有一个播放器？
3. 比赛材料是否来得及按新定位重做？

## 3. v0.6 - v0.8 迭代规划

原则：每个版本独立可发布、可回滚；先合并部署再开下一个；不并行铺功能。

### v0.6 · 儿童模式与内容分级

目标：验证「儿童粤语启蒙」是否成立，而不是全面改版。

范围：

- 新增「儿童模式」入口与开关，默认保持现有模式不变
- 儿童模式隐藏鬼故事，野史标记为「家长陪同」
- 故事增加年龄/难度标签：启蒙、亲子、进阶
- 儿童模式放大字号、简化导航、减少次要信息
- 儿童模式下隐藏 AI 工坊的开放式生成，避免不可控内容
- 家长说明页：适龄范围、录音只在本机、如何陪读

不做：

- 不做账号、班级、排行榜
- 不接支付
- 不重做全部故事封面

验收：

- 儿童模式可独立浏览、读故事、录音、听我家的版本
- 鬼故事在儿童模式不可见
- 退出儿童模式后原有功能不受影响
- 双端构建通过，移动端可用

### v0.7 · 学习闭环

目标：从「读故事」变成「听、跟读、认词、小测」四步。

范围（按优先级裁剪）：

- 每幕跟读：播放原声/示例 → 孩子录 → 回放对比
- 粤拼或关键词卡：每幕 1-2 个词，含意思和例句
- 故事后 3 道理解小测，答完给一句鼓励
- 本机学习小结：读了几幕、录了几段、认识几个词
- 家长视角：听孩子的录音、看转写、决定是否保留

不做：

- 不做自动发音评分（避免误导）
- 不做排名、积分、连续打卡压力设计
- 不做儿童社交

验收：

- 一个故事可以完整走完「听 → 录 → 认词 → 小测 → 小结」
- 录音仍只存本机，可随时删除
- 不录音也能完成阅读和小测

### v0.8 · 内容补充与真实试用

目标：让儿童定位有足够内容支撑，并拿到真实反馈。

范围：

- 新增 4-6 个适龄故事：童谣、动物、节日、家务、上学
- 补充 10-15 条适龄素材与 3-5 个真人/家长录音样本（授权明确）
- 找 1-2 个家庭或一位粤语老师走一遍，记录问题
- 修复试用中暴露的阻断问题
- 更新首页与故事馆的儿童入口，但不改品牌主叙事

不做：

- 不在这一版重做全部比赛材料
- 不扩大到普通话/其他方言

验收：

- 儿童模式有独立内容池，不依赖鬼故事和野史
- 至少一次真实亲子试用记录
- 版本冻结，进入材料收尾

### 统一收尾（v0.8 之后）

- 定位拍板：儿童启蒙 / 家庭故事书 / 双入口
- 重做产品说明 PDF、PPT、3 分钟演示视频、截图
- 更新 README、比赛文档、报名信息与数字
- 录制新的演示路径：儿童模式 → 跟读 → 声音档案 → 家庭任务包
- 全站回归、部署、提交

## 5. 风险与约束

| 风险 | 应对 |
|---|---|
| 儿童定位与现有鬼故事内容冲突 | 儿童模式独立内容池，不做全量混用 |
| 4 天内做 3 个版本导致质量下滑 | 每版只做一条主线，P1 可砍，P0 必须可演示 |
| 材料重做挤压开发 | 材料统一放到 v0.8 后，不在迭代中零散修改 |
| 教育承诺过度 | 只讲「启蒙/陪读/跟读」，不宣称课程体系或提分 |
| 儿童隐私 | 保持本机存储、无账号、无上传；自动转写需家长知情 |
| 比赛类别不匹配 | 先做双入口，报名时再决定主叙事 |
