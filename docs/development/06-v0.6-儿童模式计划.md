# v0.6 版本迭代计划：儿童模式与内容分级

## 1. 版本信息

| 项 | 内容 |
|---|---|
| 版本 | v0.6 |
| 分支 | `release/v0.6` |
| 起点 | v0.5.1（20 个故事、150 条素材、本地录音、自动转写、录音联动） |
| 定位 | 在不破坏成人体验的前提下，验证「儿童粤语启蒙」是否成立 |
| 状态 | 开发中（P0、P1 完成） |

## 2. 目标

- 新增独立的「儿童模式」入口，让 4-9 岁孩子和家长可以安全使用
- 给全部故事补上适龄信息，鬼故事与不适合的内容在儿童模式不可见
- 儿童模式只保留听故事、看翻译、点方言词、录音和听我家的版本
- 成人模式保持现状，首页、故事馆、AI 工坊、声音地图不受影响
- 为 v0.7 的学习闭环留出数据结构和页面位置

## 3. 用户与场景

| 用户 | 场景 | 需要 |
|---|---|---|
| 4-6 岁孩子 + 家长 | 亲子共读，家长操作、孩子听和跟读 | 大字号、少按钮、故事短、家长说明 |
| 6-9 岁孩子 | 自己点故事、听、录 | 清晰的选择、鼓励反馈、不迷路 |
| 家长 | 判断是否适龄、管理录音 | 内容分级、隐私说明、退出儿童模式 |

本版假设（可在开发前调整）：

- 儿童模式覆盖 4-9 岁，分为「4-6 亲子」和「6-9 自己读」
- 儿童模式由家长主动进入，默认仍是现有成人入口
- 不改变比赛报名类别，等 v0.6 跑通后再决定

## 4. 体验流程

1. 顶部导航出现「儿童模式」入口
2. 进入 `/kids`，看到按年龄分组的适龄故事，没有鬼故事、没有 AI 工坊
3. 点故事进入 `/kids/[slug]`，大字号阅读，保留普通话对照和方言词
4. 每一幕可以录音，录完在故事里听「我家的版本」
5. 结局显示一张家庭声音卡
6. 点「家长入口」回到成人模式，原有功能不变

## 5. 内容分级方案

### 5.1 数据字段

在每个故事的元数据中新增：

```js
audience: "kid" | "family" | "adult",
ageBand: "4-6" | "6-9" | "10+",
kidSafe: true | false
```

规则：

- `kidSafe: true` 才会出现在 `/kids`
- 鬼故事模式一律 `kidSafe: false`、`ageBand: "10+"`
- 野史默认 `adult` 或 `family`，需要家长陪同，不进入儿童首页
- 正经模式按内容细分：童谣、动物、节日、家庭记忆优先进入 4-6；地方传说、历史人物进入 6-9
- 每个故事保留一句 `kidNote`（可选），说明家长需要注意什么

### 5.2 初步分级原则

| 类型 | 示例 | 处理 |
|---|---|---|
| 童谣、动物、日常 | 月光光、老鼠娶亲、鸡公仔 | 4-6，kidSafe |
| 节日、家务、食物 | 龙舟饭、清明拜山、艇仔粥 | 6-9，kidSafe，家长陪同 |
| 地方传说、历史 | 五羊传说、陈家祠、光孝寺 | 6-9，kidSafe |
| 野史、灵异、复杂社会关系 | 十三行、陈梦吉、鬼故事 | 不进儿童模式 |

具体 20 个故事的归属在开发时逐条填表，并由 `validate-content.mjs` 强制检查。

## 6. 页面与路由

| 路由 | 作用 |
|---|---|
| `/kids` | 儿童首页：年龄分组、适龄故事、家长说明入口 |
| `/kids/[slug]` | 儿童阅读页，复用 `StoryReader`，加儿童样式与简化外壳 |
| `/kids/record` | 儿童录音页（P1，已完成），只保留故事、片段、录音、保存 |
| `/kids/parent` | 家长说明与退出入口（P1） |

导航处理：

- `SiteHeader` 通过 `usePathname()` 判断是否在 `/kids` 下
- 儿童模式显示简化导航：故事、我的录音、家长入口
- 成人模式新增「儿童模式」入口，不改变现有导航结构

## 7. 技术方案

### 7.1 内容数据

- 在 `lib/stories.js` 及各故事文件中补 `audience`、`ageBand`、`kidSafe`、`kidNote`
- 新增 `lib/kids.js`：
  - `kidStories()` 过滤适龄故事
  - `kidGroups()` 按年龄分组
  - `isKidSafe(slug)` 供路由与校验使用
- `scripts/validate-content.mjs` 增加检查：
  - 每个故事必须有合法分级字段
  - `kidSafe: true` 的故事不能是鬼故事
  - 儿童故事必须至少有一个结局、无悬空引用

### 7.2 页面复用

- `/kids/[slug]` 复用 `StoryReader`，传入 `kidMode`：
  - 大字号、减少次要信息、隐藏「去声音地图」
  - 保留 SceneAudio、翻译、方言词、家庭声音卡
- `/kids` 使用独立卡片样式，不复用成人 `library-card`
- 儿童样式统一挂在 `.kids` 命名空间，避免影响成人页面

### 7.3 模式与隐私

- 儿童模式不要求登录，不做年龄验证
- 录音仍只存 IndexedDB，不上传
- 儿童模式隐藏 AI 工坊入口；直接访问 `/studio` 仍是成人功能
- 家长说明页写明：适龄范围、录音只在本机、如何删除、自动转写可能使用浏览器语音服务

## 8. 优先级

### P0（必须）

- 20 个故事分级字段与内容校验
- `/kids` 年龄分组首页，只显示 kidSafe 故事
- `/kids/[slug]` 儿童阅读页，复用录音与家庭声音卡
- 儿童模式导航与「家长入口」
- 家长说明与隐私文案
- 成人模式回归：首页、故事馆、录音、档案、AI 工坊不受影响

### P1（有余力）

- `/kids/record` 简化录音页
- 简单家长门（进入家长模式前确认）
- 成人故事卡片显示适龄标签
- 儿童模式记住上次读到的故事

### P2（本版不做）

- 账号、班级、排行榜
- 发音评分
- 支付与订阅

## 9. 三个 Sprint

### Sprint 1 · 分级与儿童首页

- 补全 20 个故事分级字段
- 新增 `lib/kids.js` 与校验规则
- 完成 `/kids` 首页、年龄分组、儿童卡片
- 验收：儿童首页只出现适龄故事，鬼故事不可见

### Sprint 2 · 儿童阅读与录音

- `/kids/[slug]` 复用 Reader，接入儿童样式
- 儿童模式导航、家长入口
- 录音与 SceneAudio 在儿童路由可用
- 验收：读完一个故事，录一段，能在故事里听到我家的版本

### Sprint 3 · 简化录音、隐私与回归

- `/kids/record` 简化页
- 家长说明页、隐私文案
- 成人模式全量回归、移动端检查
- 双端构建与部署
- 验收：儿童与成人两条路径都可用

## 10. 验收标准

- `/kids` 不出现鬼故事、野史和 AI 工坊入口
- 儿童阅读页字号、按钮和间距在手机上可正常使用
- 儿童模式可以录音、播放、查看转写，刷新后仍在
- 家长入口能回到成人模式，成人功能全部正常
- 分级字段与校验脚本通过
- standalone 与静态导出构建通过
- 线上 `/kids`、`/kids/[slug]` 可访问

## 11. 风险

| 风险 | 应对 |
|---|---|
| 内容分级不均，儿童池太小 | 先把 8-10 个正经故事分进 4-6/6-9，v0.8 再补新故事 |
| 儿童模式做成「换皮」 | 必须有独立首页、导航、字号和内容过滤，不能只加标签 |
| 家长门打扰体验 | P1 再做，先用显式「家长入口」按钮 |
| 直接访问成人路由 | 本版不做强拦截，靠导航隔离；如需可加提示 |
| 比赛材料与定位不一致 | 收尾统一重做，不在本版改旧 PDF/PPT |

## 12. 开发前待确认

1. 儿童模式是否默认关闭、由家长主动进入？

3. 儿童模式是否保留家庭声音卡？
4. 是否需要在 `/kids` 放「家长说明」第一屏？
