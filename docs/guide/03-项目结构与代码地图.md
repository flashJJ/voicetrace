## 3. 关键文件职责

### 数据与内容

| 文件 | 职责 |
|---|---|
| `lib/stories.js` | 正经模式故事、`storyModes`、`stories`、`featuredStories`、`getStory` |
| `lib/stories-ghost.js` | 鬼故事模式故事 |
| `lib/stories-wild-history.js` | 野史模式故事 |
| `lib/corpus.js` | 聚合 23 个资料库 JSON，提供搜索、筛选、统计、黄金样品 |
| `lib/image.js` | 按 `NEXT_PUBLIC_BASE_PATH` 拼接封面路径 |
| `data/corpus/` | 91 条素材，按门类拆分子目录 |
| `data/generated/demo-stories.json` | `/demo` 使用的真实模型预生成产物 |

### 组件

| 文件 | 职责 |
|---|---|
| `StoryReader.jsx` | 分支叙事：当前幕状态、选项跳转、结局、进度 |
| `AudioButton.jsx` | `speechSynthesis` 朗读，等待 `voiceschanged`，失败时给文字提示 |
| `ShareCard.jsx` | Canvas 绘制故事卡，引文最多 3 行，超出截断 |
| `StoryCard.jsx` | 故事馆卡片 |
| `StoryMap.jsx` | 坐标分组、重叠节点下拉、键盘与外部点击关闭 |
| `CorpusLibrary.jsx` | 搜索、多维筛选、12 条/页分页、详情、JSON 导出 |
| `VoiceMoment.jsx` | 首页逐字点亮的粤语童谣波形 |
| `SiteHeader.jsx` | 桌面导航与移动端汉堡菜单，静态站外链 AI 工坊 |
| `SiteFooter.jsx` | 页脚与声明 |

### 工具与配置

| 文件 | 职责 |
|---|---|
| `lib/rate-limit.js` | 固定窗口计数、IP 提取、单飞锁、429 响应 |
| `lib/live.js` | 在线工坊地址与静态站判断 |
| `scripts/build-static.mjs` | 临时移走 `app/api`，以 `STATIC_EXPORT=true` 构建 |

## 4. 一次请求的路径

### 阅读故事

```text
/stories/moonlight
  → app/stories/[slug]/page.js（构建期已生成 HTML）
  → components/StoryReader.jsx（客户端接管分支状态）
  → 点「听这一段」 → AudioButton → speechSynthesis
  → 读完 → ShareCard → Canvas → 下载 PNG
```

### 生成故事

```text
/studio
  → 选素材或输入文本
  → POST /api/generate-story
  → route.js：校验 → 限流 → 拼 Prompt → 调模型
  → NDJSON 流（心跳 + 最终结果）
  → 前端解析 → 渲染三幕与 7 项验收
```

### 浏览器数据

没有账号体系。阅读进度、分支选择只存在组件 state，刷新即重置；分享卡在本地生成，不上传服务器。

## 5. 常见改动落点

| 想做什么 | 改哪里 |
|---|---|
| 新增一个互动故事 | 对应 `lib/stories*.js`，必要时补封面与地图坐标 |
| 新增一条资料库素材 | `web/data/corpus/<门类>/*.json`，注意 `modes` 字段 |
| 调整三种模式的语气 | `app/api/generate-story/route.js` 的 `SYSTEM_PROMPT` 与 `buildPrompt` |
| 调整验收规则 | `route.js` 的 `validate` 与 `data/corpus/golden/*.json` |
| 调整生成长度 / 超时 | 环境变量 `LLM_MAX_TOKENS`、`LLM_TIMEOUT_MS` |
| 调整限流额度 | 环境变量 `RATE_LIMIT_*`，逻辑在 `lib/rate-limit.js` |
| 改首页首屏 | `app/page.js` + `components/VoiceMoment.jsx` |
| 改静态站跳转 | `lib/live.js` |
| 改部署方式 | `next.config.mjs`、`scripts/build-static.mjs`、`.github/workflows/pages.yml` |

## 6. 代码约定

- 页面与组件全部使用函数组件和 Hooks，不引入类组件。
- 服务端数据在构建期读取，页面不发起数据请求（`/studio` 除外）。
- 所有静态资源路径经过 `lib/image.js` 或 `basePath` 拼接，禁止写死 `/covers/...`。
- 新增交互组件时优先复用 `globals.css` 中的 CSS 变量，不引入新的颜色体系。
- 组件涉及浏览器 API 时必须声明 `"use client"`，并处理 `window` 不存在的情况。
- 生成类改动必须先跑 `npm run build`，静态导出与服务端构建都要通过。

## 7. 不该做的事

- 不要在客户端读取或传递 `LLM_API_KEY`。
- 不要把 `.env.local`、密钥、临时部署包提交进仓库。
- 不要为静态站新增依赖服务端的功能而不做降级。
- 不要在 `globals.css` 之外新增全局样式文件，避免优先级失控。
