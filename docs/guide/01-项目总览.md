# 01 · 项目总览

> 最后更新：2026-11-17
>
> 适用对象：第一次接触本仓库的开发者、评审、后续接手者。

## 1. 项目是什么

**声迹 · VoiceTrace** 是一本方言语互动故事书。

它把粤语童谣、民间传说和家庭口述，做成可以点、可以听、可以玩、可以分享的网页故事：读者在关键情节做选择，走到不同结局，最后得到一张可以发给家人的声音故事卡。

一句话定位：

> 趁还会唱，把乡音留下来。

产品不把自己做成方言翻译器。翻译只负责让人听懂，真正的主角是原声和故事本身。

## 2. 要解决的问题

- 方言正在从家庭日常里消失，年轻人听得懂一点，但不会讲、不会唱。
- 长辈的故事只存在于饭桌和骑楼下，没有载体，也没有被记录的理由。
- 已有的方言产品大多偏工具（翻译、词典、语音识别），缺少让人愿意读完、愿意转发的叙事体验。

声迹选择的切口是「互动故事 + 声音卡」：让方言先变得好玩，再谈保存。

## 3. 核心体验

| 环节 | 用户做什么 | 产品给什么 |
|---|---|---|
| 进入 | 打开首页 | 逐字点亮的粤语童谣波形，普通话译文同步出现 |
| 读故事 | 在故事馆选一个故事 | 3-5 幕分支叙事，每幕有粤语原文、普通话翻译、方言词注释 |
| 听 | 点「听这一段」 | 浏览器语音合成朗读，作为无声环境的补充 |
| 做选择 | 在分支处点选 | 走向不同结局，结局带一句收束文案 |
| 分享 | 读完后生成分享卡 | Canvas 绘制 1080×1440 故事卡，可直接下载 |
| 探索 | 打开声音地图 | 按地区浏览故事，同坐标故事合并为一个节点下拉选择 |
| 创作 | 进入 AI 工坊 | 选资料库素材或输入自定义文本，真实模型生成 3 幕故事并自动验收 |

## 4. 三种叙事模式

同一批粤语素材，用三种语气讲给不同的人：

| 模式 | 受众 | 语气 | 边界 |
|---|---|---|---|
| 正经 / 温情 | 家庭、长辈、全年龄 | 克制、温暖 | 不煽情、不虚构史实 |
| 鬼故事 | 年轻人、悬疑爱好者 | 第一人称、夜色、留白 | 不血腥、不低俗、结尾用民俗解释 |
| 野史 | 年轻人、喜欢八卦的人 | 说书人口吻、俏皮 | 明确标注「据传 / 听讲」，不冒充正史 |

## 5. 当前内容规模

| 维度 | 数量 |
|---|---|
| 互动故事 | 12 个（正经 5 + 鬼故事 3 + 野史 4） |
| 资料库素材 | 110 条，分 25 个 JSON 文件 |
| 黄金样品 | 8 个（正经 6 + 鬼故事 1 + 野史 1） |
| 自动验收项 | 7 项 |
| 页面 | 8 个路由（含动态故事页） |

每个故事固定结构：5 幕、6 个选择、4 个唯一目标场景、2 个结局、若干方言词注释。

## 6. 页面地图

| 路由 | 作用 |
|---|---|
| `/` | 首页：定位、首屏声音卡、故事馆入口、三种模式、玩法说明、宣言 |
| `/stories` | 故事馆：按模式分组列出全部故事 |
| `/stories/[slug]` | 故事阅读器：分支叙事、语音、注释、分享卡 |
| `/map` | 声音地图：按坐标展示故事，重叠节点合并 |
| `/library` | 粤语资料库：搜索、筛选、分页、详情、导出 |
| `/demo` | 预生成演示：真实模型产物，现场不用等生成 |
| `/studio` | AI 工坊：素材 → 生成 → 自动验收 |
| `/about` | 为什么做声迹、边界与隐私说明 |

## 7. 当前状态

已完成：

- 12 个互动故事全部可读、可分支、可分享
- 资料库 110 条可按类型、地区、模式筛选并分页
- 3 段 CC BY 4.0 真人粤语录音（67-74 秒）在 `/about` 播放并署名
