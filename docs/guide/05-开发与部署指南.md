# 05 · 开发与部署指南

> 最后更新：2026-11-17

## 1. 环境要求

- Node.js 20.9 或更高（CI 使用 22）
- npm 10+
- Windows / macOS / Linux 均可

## 2. 本地运行

```bash
cd web
npm install
npm run dev
```

打开 http://localhost:3000 。

`npm run dev` 使用服务端模式，`/studio` 可以调用本地 `/api/generate-story`。

### 2.1 环境变量

复制 `web/.env.example` 为 `web/.env.local`，按需填写：

| 变量 | 必填 | 说明 |
|---|---|---|
| `LLM_API_KEY` | 真实生成必填 | 模型平台 Key，只放服务端 |
| `LLM_BASE_URL` | 否 | 默认 `https://api.openai.com/v1`；火山方舟填 `https://ark.cn-beijing.volces.com/api/plan/v3` |
| `LLM_MODEL` | 否 | 默认 `gpt-4o-mini`；方舟示例 `deepseek-v4.1-flash` |
| `LLM_DISABLE_THINKING` | 否 | 方舟端点默认 `true`，设为 `false` 可恢复思考 |
| `LLM_MAX_TOKENS` | 否 | 默认 1500 |
| `LLM_TIMEOUT_MS` | 否 | 默认 15000 |
| `RATE_LIMIT_PER_MINUTE` | 否 | 有 Key 时每 IP 每分钟，默认 5 |
| `RATE_LIMIT_PER_DAY` | 否 | 有 Key 时每 IP 每天，默认 30 |
| `RATE_LIMIT_GLOBAL_DAY` | 否 | 有 Key 时全站每天，默认 300 |
| `MOCK_RATE_LIMIT_PER_MINUTE` | 否 | 无 Key 时每 IP 每分钟，默认 20 |
| `MOCK_RATE_LIMIT_PER_DAY` | 否 | 无 Key 时每 IP 每天，默认 200 |
| `MOCK_RATE_LIMIT_GLOBAL_DAY` | 否 | 无 Key 时全站每天，默认 2000 |

`.env.local` 不提交仓库。

## 3. 构建

### 3.1 服务端构建（standalone）

```bash
cd web
npm run build
```

产物在 `web/.next/standalone`。只启动 `server.js` 会缺静态资源，本地预览需要补齐：

```powershell
Copy-Item -Recurse -Force "web\.next\static" "web\.next\standalone\.next\static"
Copy-Item -Recurse -Force "web\public" "web\.next\standalone\public"
$env:PORT=3000
node "web\.next\standalone\server.js"
```

### 3.2 静态导出（GitHub Pages）

```bash
cd web
node scripts/build-static.mjs
```

脚本会临时把 `app/api` 移出、以 `STATIC_EXPORT=true` 构建，结束后恢复。产物在 `web/out`，路径前缀为 `/voicetrace`。

> 不要直接 `STATIC_EXPORT=true next build`。`app/api` 存在时静态导出会失败，必须用脚本临时移走。

## 4. 部署

### 4.1 GitHub Pages（自动）

- push 到 `main` 触发 `.github/workflows/pages.yml`
- 工作流：`npm ci` → `node scripts/build-static.mjs` → 上传 `web/out`
- 首次部署需在仓库 `Settings → Pages → Source` 选择 **GitHub Actions**
- 地址：https://flashjj.github.io/voicetrace/

静态站的能力边界：不能调用 `/api/generate-story`，`/studio` 会显示跳转提示，导航中的「AI 工坊」直接外链到服务端版本。

### 4.2 Trae FunctionWeb（手动）

用于提供真实的 `/studio` 生成能力。

部署包要求：

- 运行时 `nodejs20`
- 单一前台进程，监听 `0.0.0.0:8000`
- 构建脚本产出 `dist/`，包含 standalone、`.next/static`、`public`、`run.sh`
- 不写运行时文件；如必须写，只能写 `${TMPDIR:-/tmp}`
- 运行环境变量通过部署配置注入，不打包 `.env`

`build.sh` 的最小形态：

```sh
#!/bin/sh
set -eu

export NPM_CONFIG_REGISTRY='https://registry.npmjs.org/'
npm ci --registry='https://registry.npmjs.org/'
npm run build

rm -rf dist
mkdir -p dist
cp -R .next/standalone/. dist/
mkdir -p dist/.next
cp -R .next/static dist/.next/static
if [ -d public ]; then
  cp -R public dist/public
fi
cp run.sh dist/run.sh
chmod 755 dist/run.sh
```

`run.sh`：

```sh
#!/bin/sh
set -eu

export HOSTNAME=0.0.0.0
export PORT="${PORT:-8000}"
exec node server.js
```

部署配置中把 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` 放进运行时环境。重新部署时环境变量需要重新提供，平台不会自动沿用旧值。

## 6. 常见问题

### 静态导出报 `export const dynamic = "force-static"` 相关错误

`app/robots.js` 必须是静态路由，文件顶部保留：

```js
export const dynamic = "force-static";
```

### 图片 404

- 静态站路径必须带 `/voicetrace` 前缀，统一用 `lib/image.js` 的 `cover()`
- 新图放 `web/public/covers/`，文件名与 `slug` 一致
- 确认 `next.config.mjs` 的 `basePath` 与 `assetPrefix` 生效

### 首屏图片高度不对

`<img>` 的 HTML `height` 属性会压制 CSS `aspect-ratio`。在样式里显式写 `height: auto`。

### `/studio` 返回 504

网关在模型返回前超时。确认：

- 接口走 NDJSON 流并每 4 秒发心跳
- `LLM_TIMEOUT_MS` 小于网关超时（当前 15 秒）
- 模型端已关闭 thinking

### 生成报「模型输出被长度限制截断」

调大 `LLM_MAX_TOKENS`，或缩短要求。当前默认 1500。

### 本地正常、线上 401

检查部署运行时环境是否真的注入了 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`，以及 `LLM_BASE_URL` 是否包含正确的 API 版本路径。

### 多实例下限流不准

限流是进程内计数，实例上限 10，各实例独立。需要精确控制时接入 Redis 做共享计数，或下调全站日额度留出余量。

## 7. 代码提交约定

- 一次提交只做一件事，提交信息用 `feat:` / `fix:` / `docs:` / `chore:` 前缀
- 改动功能时同步更新 `README.md` 的变更记录
- 新增或调整文档时更新 `docs/README.md` 索引
- 不提交构建产物：`.next`、`out`、`node_modules`、临时部署包
