## 1. 拍摄前准备

### 1.1 环境

- 浏览器：Chrome / Edge，100% 缩放，隐藏书签栏。
- 桌面视口：1440 × 900；手机视口：390 × 844（Device Toolbar）。
- 网络：优先使用 Trae 服务端地址，确保 `/studio` 可展示真实结果；静态版用 `/demo` 兜底。
- 主题：浅色，关闭夜间模式与系统通知。

### 1.2 演示数据

- 儿童线：提前完成《氹氹转，菊花圆》的前两幕与 3 道小测，让 `/summary` 有真实统计。
- 跟读：提前录一段 3-5 秒练习音频，截图时停在回放状态，避免现场麦克风权限。
- 成人线：打开《月光光》第二幕，展开一张词卡。
- 录音档案：只使用自测录音，确认没有真实家庭姓名与地址。
- AI 工坊：提前生成或打开 `/demo` 的正经模式结果，显示幕数、骨架与 8 项检查。

### 1.3 目录与命名

统一保存到：

```text
deliverables/screenshots/v0.8/
```

命名规则：`序号-页面-视口.png`，例如 `04-kids-home-desktop.png`。导出后压缩为 WebP 副本，保留 PNG 原图。

## 4. 拍摄脚本

### 4.1 桌面（每张 1-2 分钟）

1. 打开目标路由，等待字体与封面加载完成。
2. 滚动到目标区域，确保标题、按钮和至少一处关键内容同屏。
3. 使用系统截图或浏览器 DevTools Capture screenshot。
4. 检查：无加载骨架、无 404 图片、无控制台错误提示。
5. 按命名保存到 `deliverables/screenshots/v0.8/`。

### 4.2 手机视口

1. 打开 DevTools Device Toolbar，选择 390 × 844。
2. 确认无横向滚动条。
3. 儿童页需看到跟读按钮、词卡与返回入口。
4. 截图后检查按钮触控面积，必要时记录问题而不是修图。

### 4.3 AI 工坊

1. 优先使用 Trae 服务端 `/studio`，选择一条黄金样品素材。
2. 使用预生成结果，避免现场等待。
3. 画面必须包含：幕数 / 骨架、8 项检查名称与通过状态。
4. 若只有静态环境，打开 `/demo`，不要伪造 `/studio` 截图。

## 5. 隐私与合规

- 不截 API Key、环境变量、终端中的密钥、部署后台。
- 不截真实家庭录音文件名、姓名、住址、电话。
- 儿童截图使用自测数据；不展示真实儿童正脸与姓名。
- 所有截图保留真实界面边框，不用设计稿或 AI 图冒充实拍。
