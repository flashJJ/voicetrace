# 06 · 粤语故事资料库与 Agent 黄金样品

> 目标：用低成本、可追溯的公开素材，先把“量”和“评测基准”做出来，再对接 AI；不做人工录入。  
> 当前规模：**164 条素材 + 8 个黄金样品**（2026-11-20）。  
> 位置：`web/data/corpus/`，可在 `/library` 页面浏览、搜索、筛选、导出。

## 1. 为什么先做资料库

人工录入成本高、速度慢，而且会把手艺人的时间耗在“打字”上。更合理的顺序是：

1. **搜集公开素材**：童谣、传说、民俗、谚语、谜语，先形成规模。
2. **结构化入库**：统一字段、来源、授权、标签、母题、方言词。
3. **挑黄金样品**：为每一类素材定义“期望输出”，作为 Agent 的回归测试基准。
4. **再对接 AI**：ASR、翻译、分幕、注释、内容安全都用黄金样品验收。
5. **最后再考虑真实录音**：真实录音是加分项，不是前置条件。

> 结论：**资料库是底座，黄金样品是标尺，AI 是后面的加速器。**

## 3.1 覆盖与缺口

**已覆盖**：

- 地区：广州（越秀/海珠/荔湾/白云/黄埔/番禺/花都/增城/从化）、佛山（禅城/南海/顺德）、江门（新会）、韶关（珠玑巷）、珠三角。
- 类型：童谣、传说、民间故事篇目、歇后语、天气/农谚、民俗/节庆/饮食、谜语、绕口令。
- 主题：城市起源、神仙传说、风物特产、生育/祈福、工匠/非遗、年俗/节庆、饮食、方言双关。

**仍可扩充（下一轮）**：

- 地方风物：光孝寺、六榕寺、陈家祠、沙面、黄埔古港、莲花山、宝墨园、余荫山房、开平碉楼、七星岩、鼎湖山。
- 民俗/表演：粤剧、广东音乐、凉茶、煲汤、盆菜、九大簋、龙舟说唱。
- 更多歇后语：豆腐佬担梯、隔年通胜、幡杆灯笼、无耳藤喼、生虫拐杖等。
- 香港/澳门粤语素材：需要单独核对版权与用字。
- 口述史/家族故事：需要真实授权，优先级低于公开素材。

> 第一轮先把“可追溯、可结构化、可评测”做出来；不追求一次穷尽。`/library` 页面支持继续追加。

## 4. 单条素材字段

```json
{
  "id": "yue-legend-five-goats",
  "type": "legend",
  "title": "五羊传说",
  "subtitle": "广州为什么叫羊城、穗城",
  "region": "广州 · 越秀",
  "dialect": "粤语（广府片）",
  "modes": ["heritage", "wild_history"],
  "summary": "……",
  "text": "……",
  "tags": ["传说", "广州", "五羊"],
  "motifs": ["五仙", "五羊", "谷穗"],
  "glossary": [
    { "term": "五羊", "meaning": "五只仙羊", "note": "广州“羊城”之名的来源。" }
  ],
  "source": [
    { "title": "广州市政府……", "url": "https://……", "license": "government-fact" }
  ],
  "license": "government-fact",
  "storyPotential": 5,
  "difficulty": 2,
  "goldenSample": true,
  "needsResearch": false
}
```

**字段说明**：

| 字段 | 用途 |
|---|---|
| `type` | 童谣/传说/篇目/歇后语/农谚/民俗/谜语/绕口令 |
| `modes` | 可用于哪些叙事模式：`heritage` / `ghost` / `wild_history` |
| `summary` | 1-3 句摘要，用于检索、卡片、Agent 输入 |
| `text` | 原文或节选；传说/民俗可为空 |
| `motifs` | 母题，用于跨故事检索和生成 |
| `glossary` | 方言词注释，后续翻译/注释模块的评测点 |
| `source` | 来源链接 + 授权类型，保证可追溯 |
| `storyPotential` | 1-5，评估改成互动故事的潜力 |
| `difficulty` | 1-5，评估翻译/分幕难度 |
| `needsResearch` | 篇目/文本待补充，避免假装完整 |
| `kidSafe` | 是否适合进入儿童模式；v0.8 起要求配套 `ageBand` |
| `ageBand` | `4-6` 或 `6-9`，仅适龄素材需要 |

## 5. 黄金样品

黄金样品是“输入 + 期望输出 + 检查项”的 JSON。当前 8 个：

| 样品 | 素材 | 模式 | 重点验证 |
|---|---|---|---|
| `golden-moonlight-v1` | 月光光 | 正经 | 童谣分幕、方言词、翻译 |
| `golden-five-goats-v1` | 五羊传说 | 正经 | 传说实体、结局、翻译 |
| `golden-hoxiangu-v1` | 何仙姑与挂绿 | 正经 | 地名/物产、绿丝线母题 |
| `golden-lun-wenxu-v1` | 伦文叙故事 | 正经 | 人物、状元及第粥、寓意 |
| `golden-polo-chicken-v1` | 波罗鸡——靠黐 | 正经 | 歇后语双关、解释 |
| `golden-flower-street-v1` | 行花街 | 正经 | 民俗准确性、场景化 |
| `golden-haizhuang-ghost-v1` | 海幢寺·鹰爪兰 | 鬼故事 | 悬疑语气、不血腥、民俗解释 |
| `golden-chen-mengji-wild-v1` | 陈梦吉·扭计 | 野史 | 说书人口吻、标注“野史” |

**黄金样品结构**：

```json
{
  "id": "golden-moonlight-v1",
  "storyId": "yue-rhyme-moonlight",
  "mode": "heritage",
  "input": { "title": "月光光", "text": "……" },
  "expected": {
    "language": "yue",
    "entities": ["月光", "地堂", "虾仔"],
    "glossary": [{ "term": "地堂", "meaning": "天井" }],
    "scenes": [
      { "act": 1, "title": "……", "summary": "……", "choices": ["……", "……"] }
    ],
    "endings": ["……"],
    "translationZh": "……",
    "safetyFlags": []
  },
  "checks": ["json_schema_valid", "scene_count == 3", "glossary_terms_present"]
}
```

**常用检查项**：

- `json_schema_valid`：输出符合 schema。
- `language == 'yue'`：语种识别正确。
- `act_count 3-8`：幕数在 3-8 之间。
- `plan_matches`：输出符合预先声明的幕数与分支计划。
- `glossary_terms_present`：方言词注释覆盖。
- `translation_present`：普通话翻译存在。
- `no_hallucinated_entities` / `entities_are_grounded`：实体不超出素材。
- `moral_or_ending_present`：有结局/寓意。
- `explains_double_meaning`：歇后语双关解释正确。
- `custom_accuracy`：民俗事实准确。

## 6. 来源与授权

| 授权类型 | 含义 | 使用建议 |
|---|---|---|
| `traditional-public-domain` | 传统口传文学/童谣/谚语 | 可用；具体整理版本可能另有版权，正式商用前复核 |
| `government-fact` | 政府/官方网站事实 | 只提取事实并改写，不直接复制长段原文 |
| `reference` | 参考网页/书目 | 仅作线索，正文需原创改写或取得授权 |
| `original-retelling` | 本项目原创改写 | 可用；标注来源 |

**原则**：

- 不直接抓取/商用中国语言资源保护工程等官方语料。
- 不使用未授权的影视、短视频、音乐、图片。
- 传说/民俗只写“流传版本”，不冒充学术定论。
- 正式商用前，逐条复核来源与授权。

## 7. 如何扩展

1. 在对应 JSON 文件里新增一条，字段与第 4 节一致。
2. 至少提供 1 个 `source`；不确定授权时用 `reference` 并标 `needsResearch`。
3. 如果素材适合做互动故事，补 `storyPotential` 和 `glossary`。
4. 如果要作为黄金样品，在 `golden-samples.json` 增加输入、期望输出、检查项。
5. 运行校验：

```bash
node -e "const fs=require('fs'); ['nursery-rhymes','legends','proverbs','customs','story-catalog','riddles'].forEach(f=>{const d=JSON.parse(fs.readFileSync('data/corpus/'+f+'.json','utf8')); console.log(f,d.length)})"
```

6. 打开 `/library` 检查搜索、筛选、详情、黄金样品。

## 8. 下一步：对接 AI

> 已实现：`/studio` AI 工坊 + `app/api/generate-story/route.js`。  
> 有 `LLM_API_KEY` 时调用真实模型；没有时返回黄金样品作为 Mock 输出。每次输出自动对照黄金样品做检查。

**真实模型验收记录**：

- 模型：火山方舟 Agent Plan · `deepseek-v4.1-flash`
- **历史记录（2026-11-15，7 项检查）**：8 个黄金样品全部 7/7 通过；`/studio` 选“五羊传说 · 正经模式”，返回《五羊衔穗，石与声》，3 幕完整。
- **规则升级（v0.4 起）**：检查项调整为 8 项，增加幕数 3-8 与 `plan_matches`，支持 4 种叙事骨架与 seed 可复现。
- 注意：历史 7/7 记录不等同于新 8 项规则下的结果；演示时以现场检查为准，不把旧记录写成新规则的全通过。
- 单篇耗时：约 36-66 秒（推理模型，演示时建议预生成或加“正在生成”提示）
- 配置：`web/.env.local`（不提交、不显示 Key）
- 失败修正：在 prompt 中加入“必须覆盖的方言词”和“entities 必须逐字来自素材/地区/标签”，并把 `region` 加入 grounding 文本

| 能力 | 输入 | 输出 | 用哪个黄金样品验收 |
|---|---|---|---|
| 粤语 ASR | 用户录音（可选） | 粤语文本 | 月光光、行花街 |
| 普通话翻译 | 粤语文本 | 普通话译文 | 月光光、五羊传说 |
| 方言词注释 | 粤语文本 | term/meaning/note | 波罗鸡、月光光 |
| 3-8 幕分幕 | 素材摘要与叙事计划 | 3-8 幕 + 选择 + 结局 | 全部 8 个 |
| 内容安全 | 生成结果 | 敏感/虚构/误导标记 | 全部 8 个 |
| 故事卡生成 | 故事标题/金句 | 海报/分享文案 | 月光光、五羊传说 |

**验收顺序**：

1. 先跑“文本 → 3-8 幕结构”，不接 ASR。
2. 再跑“粤语文本 → 普通话翻译 + 方言词注释”。
3. 再跑“录音 → ASR → 文本”，用真实录音做增量测试。
4. 最后接 TTS/分享卡，不急着做真人录音采集。
