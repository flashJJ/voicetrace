# 07 · 三种叙事模式：正经、鬼故事、野史

> 背景：只做“温暖、正经、家庭”的非遗叙事，受众会偏窄，主要是老一辈和正经人。  
> 目标：用同一批粤语素材，切出三种语气，覆盖三类受众：家庭、年轻人、爱听八卦的人。  
> 原则：**素材同源，语气不同；事实分层，标注清楚；不为了猎奇牺牲尊重。**
>
> 说明：v0.6 起的「儿童模式」不是第四种叙事模式，而是独立内容池与产品入口；三种成人模式在儿童模式中均不出现。

## 1. 三种模式

| 模式 | 一句话 | 主要受众 | 情绪 | 适合场景 |
|---|---|---|---|---|
| 正经模式 `heritage` | 留住把声，讲给家里人听 | 家庭、长辈、文化爱好者 | 温暖、克制、怀旧 | 家庭聚会、睡前、文化课堂 |
| 鬼故事模式 `ghost` | 半夜唔好乱咁望 | 年轻人、悬疑爱好者 | 紧张、好奇、背后一凉 | 睡前刷手机、朋友聚会、万圣节 |
| 野史模式 `wild_history` | 听讲当年…… | 年轻人、历史八卦爱好者 | 俏皮、说书、半信半疑 | 通勤、吃饭、朋友吹水 |

**共同底线**：

- 不血腥、不低俗、不制造恐慌。
- 不宣扬迷信；鬼故事结尾要有“民俗解释/故事解释”。
- 野史必须标注“据传/野史/听讲”，不冒充正史，不诽谤真实人物。
- 真实人物、地点、非遗信息以公开来源为准；不确定就写“传说中”。

## 2. 内容映射

### 2.1 正经模式

**主打**：童谣、家庭记忆、地方风物、非遗工匠。

**已有互动故事**：

- 《月光光》——童谣 + 外婆 + 中秋
- 《老鼠娶亲》——民间故事 + 广府幽默
- 《阿婆的艇仔粥》——家庭记忆 + 珠江水上人家（示例）

**适合改写的素材**：卖懒、行花街、一盅两件、艇仔粥、香云纱、五羊传说。

### 2.2 鬼故事模式

**主打**：冤屈、投井/投湖、夜寺、龙宫、化石、花神。  
**注意**：不是“恐怖片”，是“民俗悬疑”；让人好奇，不让人不适。

**已有互动故事**：

- 《井边的鹰爪兰》——海幢寺，兰香投井，鹰爪兰化生
- 《仙湖里的金花》——金花娘娘，难产、沉香像、湖中白影
- 《龙宫煮泉》——从化温泉，采药老人、银锅、青龙

**素材池**（`modes` 含 `ghost` 的 26 条）：

- 海幢寺、金花娘娘、从化温泉、珠玑巷、萝岗香雪、素馨花、郑仙、佛山祖庙、波罗诞、盘古王诞、金花诞、郑仙诞、中秋拜月光等。

**语气模板**：

> 第一人称；先给一个具体的夜色/声音/气味；每一幕留一个“要不要继续”的选择；结尾回到现实或民俗解释。

### 2.3 野史模式

**主打**：历史人物、机智人物、南迁、庙会由来、歇后语典故。  
**注意**：野史不是造谣；要明确“野史/据传”，不要把传说写成史实。

**已有互动故事**：

- 《状元及第粥》——伦文叙，穷书生、粥铺、状元
- 《陈梦吉的扭计》——陈梦吉，整蛊地主、帮农民出头
- 《珠玑巷的夜》——罗贵、33 姓 97 户、南迁

**素材池**（`modes` 含 `wild_history` 的 69 条）：

- 伦文叙、陈梦吉、珠玑巷、越秀山/镇海楼、波罗诞、佛山祖庙、湛甘泉、太平天国、歇后语、民间故事篇目等。

**语气模板**：

> 说书人开场：“听讲当年……”；中间插一句“你信唔信？”；结尾补一句“野史唔一定真，但民间的气是真的”。

## 5. AI 提示词策略

`app/api/generate-story/route.js` 里已经按模式注入不同的模式提示：

- `heritage`：温暖、克制，适合家庭与全年龄。
- `ghost`：第一人称、夜色、悬疑；不血腥、不低俗、不宣扬迷信；结尾民俗解释。
- `wild_history`：说书人口吻、俏皮、八卦；明确“据传/野史”；不冒充正史。

**黄金样品**：

- 正经：6 个（月光光、五羊、何仙姑、伦文叙、波罗鸡、行花街）
- 鬼故事：1 个（海幢寺·鹰爪兰）
- 野史：1 个（陈梦吉·扭计）

**真实模型验收记录**：

- 火山方舟 Agent Plan · `deepseek-v4.1-flash`
- 历史记录（2026-11-15）：8 个黄金样品全部 7/7 通过
- 关键修正：prompt 里指定“必须覆盖的方言词”，并限制 entities 只能逐字来自素材/地区/标签；`region` 也纳入 grounding
- v0.4 起检查升级为 8 项（幕数 3-8、`plan_matches`），历史 7/7 不等同于新规则结果，演示时以现场检查为准

## 6. 内容生产顺序（最优解）

1. **先拆数据**：按子集拆成小文件，加 `modes` 字段（已完成）。
2. **再定模式**：三种模式的语气、边界、受众（本文档）。
3. **再做模块**：三种模式共 25 个互动故事（已完成）。
4. **再接 AI**：`/studio` 按模式生成 3-8 幕，黄金样品与 8 项检查验收（已完成）。
5. **最后扩量**：用同一套模板，从 164 条素材继续生成更多模块；儿童线使用独立内容池，不进入三种成人模式。

## 7. 风险与边界

| 风险 | 应对 |
|---|---|
| 鬼故事吓到人/低俗 | 不写血腥、暴力、性暗示；用声音、光影、悬念；结尾解释 |
| 宣扬迷信 | 明确“民间传说/故事”，不提供现实指导 |
| 野史造谣/诽谤 | 标注“据传/野史”；不编造具体年份/数字；不攻击真实人物 |
| 历史人物争议 | 只讲民间流传版本；不站队；用“传说中” |
| 平台审核 | 避免敏感政治、宗教、民族话题；必要时加提示 |
| 受众不适 | 三种模式分区；鬼故事加“胆小勿入”提示；可关闭声音 |
