# 12 · VoiceTrace「声迹」路演宣讲材料

> 更新日期：2026-11-20<br>
> 版本：v0.12.0<br>
> 用途：入围路演、作品宣讲、评委答疑、现场演示<br>
> 建议主讲版本：10 页，约 6 分钟；另附 3 分钟压缩流程<br>
> 核心表达：**一个内容底座，两扇门——大人留住声音，孩子学会开口。**

## 1. 使用前必须统一的口径

### 可以明确讲

- 28 个互动故事，3-8 幕，三种叙事模式（正经 17 / 鬼故事 5 / 野史 6）。
- 17 个独立儿童故事，4-6 岁 9 个、6-9 岁 8 个，全部有分级、封面、词卡与 3 道小测；含天星小轮、叮叮电车、茶餐厅 3 个香港原创故事。
- 164 条粤语素材，来自 29 个内容文件，其中 14 条适龄素材。
- 8 个黄金样品，真实模型按 8 项自动检查验收。
- 生成支持 3-8 幕、4 种叙事骨架与 seed 可复现。
- 本机录音、声音档案、家庭任务包；录音与学习进度默认只存浏览器。
- 无需注册、没有账号；无广告、无第三方统计，不做用户画像；自动转写可关闭。
- 全站简 / 繁 / 英切换；PWA 可安装到主屏，已访问页面离线可看；故事搜索、年龄筛选、收藏与系统分享。
- 双端部署：GitHub Pages 静态站、Trae 服务端（可实时生成）。

### 不要这样讲

- 不要说“已经完成真实亲子家庭试用”。当前只有 1 次脚本自测，真实样本为 0。
- 不要把 `docs/contest/08` 的模拟试玩报告当真实用户证据。
- 不要说“已经采集了外婆 / 长辈真人声音”。故事页是浏览器语音合成示例。
- 不要把《阿婆的艇仔粥》说成真实家庭采访，它是待替换的示例故事。
- 不要说声音地图是精准地理数据，它是示意图。
- 不要把“8 个样品通过 8 项检查”扩大成“AI 不会出错”。
- 不要在 GitHub Pages 静态版现场承诺实时生成；实时 `/studio` 需要 Trae 服务端。
- 不要说“完全不收集任何数据 / 所有数据都在本地”：开启自动转写时音频由浏览器语音服务处理，AI 工坊会把用户输入的素材文本发给模型。

### 第 2 页｜问题：声音还在，但接不住

**屏显文案**

- 长辈会讲，晚辈不一定听得懂
- 孩子想学，缺少适龄内容和可操作练习
- 方言工具多是翻译、朗读、识别，用完就走
- AI 能生成故事，也可能编造人物、地点和事件

**讲稿**

“很多家庭并不是没有故事，而是故事停在饭桌上。大人这一端，是听不懂、没整理；孩子这一端，是没有适龄入口、没人陪着练。现有方言产品大多解决‘这句话什么意思’，却没有解决‘我为什么愿意读，孩子为什么愿意开口’。”

**画面建议**

两代人的对照图：一边是长辈口述，一边是孩子跟读；不要用未经授权的老人照片。

### 第 3 页｜方案：一个底座，两扇门

**屏显文案**

> 有来源的粤语素材 → 3-8 幕故事引擎 → 同一个内容底座<br>
> 成人入口：读、听、录、整理<br>
> 儿童入口：听、跟读、认词、小测、小结

**讲稿**

“声迹不是两个产品，而是一套内容底座上的两个入口。成人入口负责留住声音，儿童入口负责让下一代开口。两条线共用故事结构、方言注释、录音能力和部署体系，但儿童线有独立内容池和学习闭环，不会把鬼故事或开放式生成推给孩子。”

**画面建议**

一个底座、两扇门的结构图；两扇门各放 2-3 个页面小截图。

### 第 4 页｜成人线：把故事变成家庭声音档案

**屏显文案**

- 3-8 幕互动、分支与多个结局
- 方言原文 + 普通话辅助 + 方言词注释
- 本机录音棚、可选自动转写、逐句校对
- 声音档案、导出 / 导入、家庭任务包

**讲稿**

“以《月光光》为例。用户在 3-8 幕里做选择，遇到‘地堂’可以直接点开注释。读完不是结束，可以进入录音棚，用手机录下自己家的版本；录音只存在本机，可以试听、转写、删除和导出。家庭任务包解决的是‘不知道怎么开始’，把一次共读拆成几个小任务。”

**现场动作**

1. 打开 `/stories/moonlight`，点“地堂”注释。
2. 做一个选择，进入下一幕。
3. 切到 `/record` 或 `/archive`，指出“本机保存”和删除入口。

### 第 5 页｜儿童线：五步学习闭环

**屏显文案**

> 听 → 跟读 → 认词 → 小测 → 小结

- 17 个独立儿童故事，4-6 岁 / 6-9 岁分组；含 3 个香港故事
- 每幕跟读、回放、重录；练习录音不写入声音档案
- 慢速 / 标准 / 原速朗读，翻译可收起；词卡可逐词发音
- 3 道小测，答错给提示，不扣分、不排名
- 学习小结 + 家长查看 / 清除

**讲稿**

“儿童线不是给成人故事加一个儿童皮肤。孩子进入 `/kids`，按年龄选故事；每一幕可以调慢语速、收起翻译先听粤语，再跟读，录音只在当前页面练习，不会混进家庭声音档案。点词卡可以听发音，最后做 3 道题，答错给提示。小结告诉孩子读了几幕、跟读几段、认识几个词。家长页可以看记录，也可以一键清除。”

**现场动作**

1. 打开 `/kids`，展示年龄分组与香港故事。
2. 打开《天星小轮过海》，切到「慢速」、收起翻译，点“跟读一次”。
3. 展开一张词卡，点一下发音。
4. 跳到结局，做 1 道小测，展示提示。
5. 打开 `/kids/parent`，指出清除入口。

### 第 7 页｜AI 工程：让“能生成”变成“可验收”

**屏显文案**

> 3-8 幕 · 4 种叙事骨架 · seed 可复现<br>
> 8 个黄金样品 × 8 项自动检查

检查：结构、幕数、计划一致、结局、方言词、翻译、实体依据、选择。

**讲稿**

“我们没有只用肉眼判断 AI 写得像不像。生成前先定叙事计划：3-8 幕、四种骨架、seed 可复现；生成后跑 8 项检查，包括结构、幕数、计划是否一致、结局是否收束、指定方言词是否覆盖、翻译是否存在、实体是否有素材依据、非结局场景是否有选择。8 个黄金样品是回归标尺，不代表 AI 永远不会错，但代表关键约束可以重复验收。”

**现场动作**

服务端打开 `/studio` 展示一次预生成结果与检查项；如果现场网络不稳，切 `/demo`。

### 第 8 页｜隐私与边界：录音不出本机

**屏显文案**

- 无需注册、没有账号，录音默认不上传
- 录音存 IndexedDB，不上传服务器
- 自动转写由浏览器语音服务处理，可关闭
- 单段 8 MB、总量 80 MB，可删除、可导出
- 无广告、无第三方统计，不做用户画像
- 儿童学习进度只存本机，家长可清除
- 儿童模式不出现鬼故事、野史、开放生成、排行榜

**讲稿**

“对家庭产品来说，隐私不是一句口号。声迹没有注册和账号，打开就能用；录音默认只存在这台设备的浏览器里，不上传服务器；页面没有广告，也没有第三方统计脚本。自动转写会明确提示由浏览器语音服务处理，可以关掉。孩子跟家长说‘我录过’，家长可以在家长页看到记录，也可以清除。清除学习记录不会误删录音，两套数据分开管理。”

**画面建议**

录音页隐私提示、家长页清除入口两张截图并排。

## 5. 评委高频问题与回答

### Q1：这和方言翻译器有什么不同？

翻译解决“这句话是什么意思”，声迹解决“我为什么愿意进入这个故事，并把它继续讲给孩子”。翻译和注释是辅助，3-8 幕选择、家庭录音和儿童学习闭环才构成完整体验。

### Q2：为什么同时做成人线和儿童线？

两条线共用内容、故事引擎、录音和部署，边际成本可控；同时只做成人线使用频次低，只做儿童线会丢掉家庭声音与三种叙事模式。v0.8 已把儿童线做成独立内容池，不依赖成人故事。

### Q3：儿童模式会不会只是给成人故事加皮肤？

不是。儿童池有独立分级、封面、词卡、小测和小结，隐藏鬼故事、野史和开放式生成；跟读练习录音不写入家庭声音档案；家长可查看和清除学习记录。

### Q4：8 个黄金样品、8 项检查能证明什么？

它证明生成结果可以在既定样品上重复验收结构、幕数与 grounding 约束，而不是每次靠肉眼判断。它不能证明所有开放输入都正确，所以仍需要人工语言润色、事实核查和版权复核；历史 7/7 记录也不等同于新 8 项规则下的结果。

### Q5：有真实用户数据吗？

目前没有可对外报告的真实亲子家庭试用。v0.8 只完成了一次脚本自测，记录在 `docs/development/09-v0.8-试用记录.md`；`docs/contest/08` 是内部模拟排练，不会当作真实完成率或用户原话。

### Q6：是真实长辈声音吗？

不是。故事页是浏览器语音合成示例，页面明确标注；真人录音需要授权、隐私保护和删除流程，是下一阶段内容。

### Q7：《阿婆的艇仔粥》是真实家庭故事吗？

不是，它是展示产品形态的示例故事，数据中已标注“待替换为真实家庭故事”。

### Q8：孩子录音安全吗？

录音只存本机 IndexedDB，不上传服务器；单段 8 MB、总量 80 MB，可删除、可导出。自动转写由浏览器语音服务处理，可关闭。儿童学习进度只存 localStorage，家长可清除。

### Q9：为什么在线 `/studio` 有时不能生成？

GitHub Pages 是静态站，没有服务端密钥和 API 路由；Trae 服务端地址支持实时生成，静态版用 `/demo` 展示真实模型预生成结果。

### Q10：声音地图中的地点准确吗？

当前是故事导航示意图，不是精确地理数据。它已经解决同坐标故事无法选择的问题，后续若使用真实经纬度，会单独核对地点来源和地图授权。

### Q11：TRAE 具体贡献了什么？

需求与信息架构、React 页面与组件、164 条素材结构化、三种模式提示词与 8 项验收、儿童模式与学习闭环、测试与双端部署。可展示对应任务记录和关键 diff。

### Q12：如何商业化？

目前仍是待验证假设。可验证方向包括家庭定制故事册、幼儿园 / 社区粤语启蒙内容、文旅机构互动故事制作。优先级要由真实试用与机构访谈决定。

## 7. 现场异常处理

| 情况 | 处理 |
|---|---|
| 在线页面打不开 | 切换 Trae 服务端；仍不可用则播放本地 MP4 |
| 模型响应慢或失败 | 不现场重试等待，直接打开 `/demo` 预生成结果 |
| 静态版没有实时生成 | 解释静态与服务端边界，展示 `/demo` 或切 Trae |
| 音频无法播放 | 继续展示原文、普通话和注释，说明语音为合成示例 |
| 儿童页录音无权限 | 说明录音是可选增强，直接展示词卡与小测 |
| 时间被压缩 | 保留《月光光》互动、儿童五步闭环、8×8 验收和收尾 |
| 被追问未实现功能 | 直接区分“已实现 / 下一步”，不现场编造用户、录音或商业数据 |
