> **不可直接作为报名帖/评审材料中的“真实用户证据”提交。**

## 1. 模拟方法

- 样本：10 个模拟用户，覆盖家庭/长辈、年轻人、文化爱好者、学生。
- 任务：
  1. 打开 `/stories`，选一个模式，完成一个故事。
  2. 打开 `/demo`，对比三种模式各一个故事。
  3. 打开 `/studio`，查看一次 AI 生成结果（预生成，避免等待）。
  4. 生成/下载一张故事卡。
- 记录：完成率、时长、评分、分享意愿、最喜欢/最困惑的点、原话。

## 4. 关键发现

1. **鬼故事/野史确实扩展受众**：19-27 岁模拟用户中，7/8 更愿意尝试非正经模式；其中 4 人明确说会分享给朋友。
2. **正经模式仍有最强情感连接**：家庭/长辈用户对“留住声音”最有感，愿意给父母/外婆用。
3. **故事长度是最大摩擦**：AI 生成的三幕每幕 150-200 字，部分用户想“快点选”；建议压到 80-120 字。
4. **非粤语用户需要辅助**：普通话翻译和方言词注释很关键；建议增加“粤语/普通话”一键切换。
5. **鬼故事需要内容提示**：2 位模拟用户提到“不知道会不会很吓人”；建议加“胆小勿入/关闭音效”。
6. **野史需要正史/野史标签**：文化爱好者希望明确“哪些是传说、哪些是史实”。
7. **预生成演示是刚需**：真实模型 30-80 秒/篇，现场等太久；`/demo` 预生成页必须作为主演示入口。
8. **技术页面对普通用户偏复杂**：`资料库`、`AI 工坊` 更适合放在“创作后台”，普通用户只需要“故事馆/演示”。

## 5. 优先修改建议

| 优先级 | 修改 | 原因 |
|---|---|---|
| P0 | 鬼故事加“胆小勿入/关闭音效”提示 | 降低不适感，避免投诉 |
| P0 | 野史加“据传/野史”标签 | 防止被误认为正史 |
| P0 | `/demo` 作为演示主入口 | 避免现场等 30-80 秒 |
| P1 | 三幕文本压到 80-120 字 | 提高完成率 |
| P1 | 增加“粤语/普通话”切换 | 降低非粤语用户门槛 |
| P1 | 分享卡加二维码 | 让分享可回流 |
| P2 | 普通用户隐藏技术页面，放入“创作后台” | 降低认知负担 |
| P2 | 增加“3 分钟听完”进度提示 | 提高完成率 |

## 7. 试玩问题清单（真实测试用）

1. 你第一眼觉得这是什么产品？会给谁用？
2. 你最喜欢哪个模式？为什么？

9. 鬼故事/野史有没有让你不舒服？
10. 你会第二次打开吗？为什么？

## 8. 结论

模拟结果支持最初的判断：**三种模式能有效扩展受众**，尤其是鬼故事/野史对年轻人；但产品还需要在“长度、内容提示、普通话辅助、预生成演示”上做一轮打磨。
