# 10 · 3 分钟演示脚本

> 目标：3 分钟内讲清“是什么、给谁用、为什么不同、怎么做的、现在到什么程度”。  
> 主演示页：`/demo`（真实模型预生成，打开即看，不用等 30-80 秒）。  
> 备用：本地生产服务 + 录屏视频。

## 1. 演示前准备

- [ ] 打开四个标签页：
  1. `/demo`（主演示）
  2. `/stories/moonlight`（正经模式）
  3. `/studio`（AI 工坊，已选“五羊传说 · 正经模式”，预生成结果已加载）
  4. `/library`（资料库，模式筛选“鬼故事”）
- [ ] 关闭无关通知；浏览器 100% 缩放。
- [ ] 录屏 1080p；麦克风测试；字幕后期加。
- [ ] 准备一段 3 分钟备用录屏（防止现场网络/模型故障）。
- [ ] 真实用户数据/截图放在桌面，随时可切。

## 2. 时间轴（总 3:00）

### 0:00-0:18 钩子

**画面**：黑底白字，或一张老照片 + 音频波形。

**旁白**：

> “外婆讲过一个很长的故事。我听懂一半，笑了一半。后来想再听，她已经不在了。”

**动作**：停 1 秒，让这句话落地。

### 0:18-0:40 问题与洞察

**画面**：切到 `/stories`，三个模式并排。

**旁白**：

> “方言在消失，但现有产品要么是翻译器，要么是官方大片。没有人做‘我家的故事’。
> 而且只做温情，受众太窄——所以我用同一批粤语素材，切了三种讲法：正经、鬼故事、野史。”

**动作**：鼠标快速划过三个模式标题：留住把声 / 半夜唔好乱咁望 / 听讲当年……

### 0:40-1:20 正经模式演示

**画面**：`/stories/moonlight`。

**旁白**：

> “这是正经模式，《月光光》。三幕，两三个选择。点一下方言词，能看到‘地堂’是什么意思；下面有普通话翻译。
> 读完生成一张声音故事卡，可以发给家里人。”

**动作**：
1. 点“地堂”注释；
2. 点一个选择，进入第二幕；
3. 滚到结局，展示故事卡；
4. 不要真的下载，展示按钮即可。

### 1:20-1:50 鬼故事 + 野史

**画面**：切到 `/demo`。

**旁白**：

> “鬼故事模式，是给年轻人的。《金花夜叫》——不血腥，结尾回到民俗解释。
> 野史模式，是给爱听八卦的人。《波罗诞：唔舍得走嘅使者》——说书人口吻，但明确标注‘据传/野史’，不冒充正史。”

**动作**：
1. 指一下两个标题和模式标签；
2. 各展示第一幕 10 秒；
3. 指一下“7/7 通过”的检查条。

### 1:50-2:20 AI + 资料库

**画面**：切到 `/studio`，展示预生成“五羊传说”。

**旁白**：

> “这不是手写死的。我们有一个 91 条的粤语资料库，按内容子集拆成 23 个文件；8 个黄金样品用来验收 AI。
> 选素材 + 模式，真实模型生成三幕、翻译、注释；8 个黄金样品全部 7/7 通过。
> 现场用预生成结果，所以不用等模型。”

**动作**：
1. 展示 `/studio` 的真实模型标签、7/7、3 幕；
2. 快速切 `/library`，展示 91 条、模式筛选“鬼故事”16 条；
3. 回到 `/demo`。

### 2:20-2:45 试玩与证据

**画面**：真实试玩截图/原话（提交前替换；排练时可用模拟报告，但不要说是真实数据）。

**旁白**：

> “我们做了 10 人试玩：9 个人能独立走完一个故事，平均 3.6 分钟；年轻人明显更愿意试鬼故事和野史。
> 【提交前替换为真实数据：例如‘X/10 完成，X 人愿意分享’，并展示真实原话。】”

**动作**：展示 1 张真实截图 + 1 句原话。

### 2:45-3:00 收尾

**画面**：回到首页/`/demo`，标题“声迹 · 方言故事书”。

**旁白**：

> “声迹想做的，不是方言工具，而是一个家庭的声音抽屉。
> 让方言不只被保存，还能被玩。”

**动作**：停 2 秒，结束。

## 4. 现场应急

| 情况 | 处理 |
|---|---|
| 网络断了 | 切本地生产服务；再不行播放备用录屏 |
| 模型超时 | 直接用 `/demo` 预生成结果，说“现场用预生成，真实模型 8/8 通过” |
| 页面打不开 | 播放 3 分钟备用视频，口述关键点 |
| 评委问“真实用户呢” | 如实说“目前是内部试玩，真实 10 人测试在进行中”；不要拿模拟数据冒充 |
| 评委问“鬼故事会不会吓人” | “不血腥、不低俗，结尾有民俗解释；会加胆小勿入提示” |
| 评委问“野史会不会造谣” | “明确标注据传/野史，不冒充正史，不诽谤真实人物” |
| 时间不够 | 砍掉 1:20-1:50 的第二幕展示，保留标题和 7/7 |

## 5. 评委可能追问

**Q：为什么不做方言翻译？**  
A：翻译是工具，用完就走；声迹做的是故事体验，用户会读、会选、会分享，情感连接更深。

**Q：素材版权怎么办？**  
A：传统童谣/传说按公有领域处理；政府网站内容只提取事实并改写；每条都有来源和授权状态；正式版替换为经授权的真实故事。

**Q：AI 会不会编造？**  
A：有 8 个黄金样品做验收；实体必须逐字来自素材/地区/标签；方言词必须覆盖资料库词条；8/8 黄金样品 7/7 通过。

**Q：商业模式？**  
A：C 端“家庭故事书”按本付费；B 端给文旅/学校/社区做定制故事；先靠比赛曝光和真实用户验证。

**Q：为什么用 TRAE？**  
A：从需求梳理、页面搭建、组件开发、数据整理、调试到部署，核心开发都在 TRAE 完成；Session ID 和截图可查。
