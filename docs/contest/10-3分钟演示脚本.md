# 10 · 3 分钟演示脚本（v0.12 双入口）

> 目标：3 分钟内讲清“是什么、给谁用、两条线怎么成立、AI 怎么验收、现在到什么程度”。
> 主演示页：`/kids/ding-ding-zyun` 与 `/stories/moonlight`。
> AI 演示：Trae 服务端 `/studio`，或 `/demo` 预生成结果。
> 备用：本地生产服务 + 3 分钟录屏。

## 1. 演示前准备

- [ ] 打开六个标签页：
  1. `/`（首页）
  2. `/stories/moonlight`（成人线）
  3. `/record` 或 `/archive`（录音与档案）
  4. `/kids`（儿童首页）
  5. `/kids/ding-ding-zyun`（儿童故事，提前展开一张词卡）
  6. `/studio`（已加载预生成结果）或 `/demo`
- [ ] 儿童页提前完成一次跟读，避免现场麦克风权限卡顿；跟读片段留作回放。
- [ ] 关闭无关通知；浏览器 100% 缩放。
- [ ] 录屏 1080p；麦克风测试；字幕后期加。
- [ ] 准备 3 分钟备用录屏，防止网络或模型故障。
- [ ] 不准备任何“真实用户数据”截图；本版没有。

## 2. 时间轴（总 3:00）

### 0:00-0:18 钩子

**画面**：黑底白字，或一张骑楼下的老照片 + 音频波形。

**旁白**：

> “阿婆会唱很多童谣。我小时候跟着唱，长大以后，只记得第一句。
> 后来我想，如果孩子连第一句都不会，这首歌就真的停了。”

**动作**：停 1 秒。

### 0:18-0:35 问题与双入口

**画面**：切到首页，再快速划过 `/kids`。

**旁白**：

> “声迹做两件事：帮大人把长辈的声音留下来，也帮 4-9 岁的孩子从听故事走到敢开口。
> 一个内容底座，两扇门。”

**动作**：鼠标从首页导航的「儿童模式」划到 `/kids` 年龄分组。

### 0:35-1:10 成人线：故事与录音

**画面**：`/stories/moonlight`。

**旁白**：

> “这是成人线。《月光光》有 3 到 8 幕，可以做选择。点一下‘地堂’，能看到它是天井、屋前的空地。
> 读完不是结束，可以进录音棚，用手机录下自己家的版本。录音只存在本机，可以试听、转写、删除和导出。”

**动作**：
1. 点“地堂”注释；
2. 做一个选择，进入下一幕；
3. 切到 `/record` 或 `/archive`，指一下“本机保存”和删除入口。

### 1:10-1:55 儿童线：五步闭环

**画面**：`/kids` → `/kids/star-ferry`。

**旁白**：

> “儿童线不是给成人故事加个儿童皮肤。这里按 4-6 岁和 6-9 岁分组，有 17 个独立故事，最近补了天星小轮、叮叮和茶餐厅 3 个香港故事。
> 每一幕可以慢速听、收起翻译先听粤语，再跟读、看词卡、听发音；读完做 3 道题，答错给提示，不扣分。
> 最后有学习小结：读了几幕、跟读几段、认识几个词、答对几题。”

**动作**：
1. 在 `/kids` 指一下两个年龄分组和 3 个香港故事；
2. 进《天星小轮过海》，把朗读速度切到「慢速」，点「收起翻译」；
3. 点「跟读一次」，回放 3 秒；
4. 展开一张词卡，点一下发音；
5. 滚到结局，点「做 3 道小测」，选一个错误选项，展示提示，再选对；
6. 切到 `/kids/parent`，指一下学习记录和「清除」。

### 1:55-2:15 家长与隐私

**画面**：`/kids/parent`。

**旁白**：

> “录音和学习进度都只存在这台设备，不上传服务器。家长能看到孩子读了多少，也可以清除。
> 清除学习记录不会删除录音，两套数据分开管理。”

**动作**：指一下家长页的隐私说明与清除按钮，不实际点击。

### 2:15-2:40 AI 与内容底座

**画面**：`/studio` 预生成结果，或 `/demo`。

**旁白**：

> “这些内容不是手写死的。我们有 164 条有来源的粤语素材、8 个黄金样品。
> 生成前先定 3 到 8 幕的叙事计划，生成后跑 8 项检查：结构、幕数、计划一致、结局、方言词、翻译、实体依据、选择。
> 现场用预生成结果，所以不用等模型。”

**动作**：
1. 展示 `/studio` 的幕数、骨架与 8 项检查；
2. 快速切 `/library`，展示 164 条与来源字段；
3. 回到 `/demo`。

### 2:40-3:00 收尾

**画面**：回到首页。

**旁白**：

> “目前有 28 个故事、17 个儿童故事、164 条素材；简繁英三语，手机上可以装到主屏，离线也能打开读过的故事。双端部署。
> 真实亲子试用还没有完成，我们不会把它写成用户数据。
> 下一步，是让更多家庭真的用起来。
> 让方言不只被保存，还能被玩。”

**动作**：停 2 秒，结束。

## 4. 现场应急

| 情况 | 处理 |
|---|---|
| 网络断了 | 已安装的 PWA 可离线打开读过的页面；否则切本地生产服务，再不行播放备用录屏 |
| 模型超时 | 直接用 `/demo` 预生成结果，说明真实模型按 8 项检查验收 |
| 页面打不开 | 播放 3 分钟备用视频，口述关键点 |
| 麦克风无权限 | 直接说明录音是可选增强，继续展示词卡与小测 |
| 评委问“真实用户呢” | 如实说“目前没有真实亲子试用，只有脚本自测，不会冒充用户数据” |
| 评委问“鬼故事会不会吓人” | “不血腥、不低俗，结尾有民俗解释；儿童模式完全不出现” |
| 评委问“野史会不会造谣” | “明确标注据传/野史，不冒充正史，不诽谤真实人物” |
| 时间不够 | 砍掉 `/record` 段落，保留儿童五步闭环与 8×8 验收 |

## 5. 评委可能追问

**Q：为什么不做方言翻译？**
A：翻译解决一句话，声迹解决一个家庭愿不愿意读、孩子愿不愿意开口。

**Q：为什么同时做儿童线？**
A：成人线留存声音，儿童线让声音继续被使用；两条线共用内容与录音能力，儿童线有独立内容池。

**Q：素材版权怎么办？**
A：传统童谣/传说按公有领域处理；公开网页只提炼事实并改写；每条有来源与授权状态；正式商用前逐条复核。

**Q：AI 会不会编造？**
A：8 个黄金样品 + 8 项检查，实体必须有素材依据；通过检查不等于永远正确，仍需人工复核。

**Q：商业模式？**
A：家庭定制故事册、幼儿园/社区粤语启蒙内容、文旅互动故事；优先级由真实试用决定。

**Q：为什么加香港故事？**
A：目标市场是香港与海外华侨家庭。天星小轮、叮叮和茶餐厅是孩子每天见到的场景，比抽象的文化介绍更容易让他们开口。

**Q：为什么要做三语和离线？**
A：香港家庭常用繁体，海外家庭需要英文；地铁和飞机上网络不稳定，装到主屏后离线也能读已打开的故事。

**Q：为什么用 TRAE？**
A：从需求、页面、数据、测试到双端部署都在 TRAE 完成；v0.6-v0.12 的迭代记录与 Session ID 可查。
