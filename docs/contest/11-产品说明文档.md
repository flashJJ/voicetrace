## 2. 产品是什么

声迹是一款以粤语和地方记忆为起点的互动叙事产品。它把童谣、传说、民俗和家庭故事组织成可以读、可以选、可以听、可以录的互动书，并提供两条清晰的入口：

1. **家庭声音故事书（成人线）**：读故事、查方言词、看普通话辅助文本、录下自家的方言版本、整理声音档案、生成家庭任务包。
2. **儿童粤语启蒙（儿童线）**：按年龄进入独立儿童池，听故事、逐幕跟读、认方言词、做 3 道小测、看学习小结，家长可以查看和清除记录。

两条线共用同一个内容底座，但儿童线不出现鬼故事、野史和开放式 AI 生成。

声迹要保留的不只是某种语言的发音，更是语言背后的人、地方和生活细节。

## 3. 双入口定位

### 3.1 为什么是双入口

- 只做成人家庭故事书：情感强，但使用频次低，孩子没有自己的入口。
- 只做儿童启蒙：目标清晰，但会丢掉鬼故事、野史和家庭录音这些已经成立的成人内容。
- 双入口共用内容、技术和录音能力，同时服务「留住长辈声音」和「让下一代敢开口」两件事。

### 3.2 两条线的关系

| 维度 | 家庭声音故事书 | 儿童粤语启蒙 |
|---|---|---|
| 核心用户 | 离乡年轻人、家庭成员、文化爱好者 | 4-9 岁孩子与家长 |
| 核心动作 | 读、听、录、整理、分享 | 听、跟读、认词、小测、小结 |
| 内容范围 | 28 个故事、三种叙事模式 | 17 个独立儿童故事 |
| 数据边界 | 录音本机保存，可导出家庭包 | 学习进度本机保存，家长可清除 |
| AI 角色 | 生成与验收，不替代素材来源 | 不进入儿童阅读路径 |

## 4. 为谁解决什么问题

### 4.1 目标用户

| 用户 | 典型需求 | 声迹提供的入口 |
|---|---|---|
| 离乡年轻人 | 想重新接触乡音，但长篇资料有距离感 | 3-8 幕互动故事、三种叙事语气、语音示例 |
| 家庭成员 | 长辈会讲，晚辈未必听得懂 | 方言原文、普通话辅助、方言词注释、家庭录音 |
| 4-9 岁孩子与家长 | 想接触粤语，但缺少适龄内容和可操作练习 | 儿童池、跟读、词卡、小测、学习小结 |
| 学校 / 社区教育者 | 需要可参与的地方文化内容 | 故事馆、儿童模式、资料库检索、来源信息 |
| 内容创作者 | 整理素材耗时，担心 AI 编造 | AI 工坊、结构化输出、黄金样品自动检查 |

### 4.2 核心问题

1. **故事没有被留下来**：许多家庭记忆只存在于口述中，缺少低门槛的整理方式。
2. **听见了，却不一定听懂**：方言词汇和文化背景形成理解门槛。
3. **孩子缺少适龄入口**：成人故事可以共读，但不等于儿童能独立完成的学习闭环。
4. **内容生产难以稳定复用**：人工分幕、翻译、注释耗时；直接使用生成式 AI 又可能出现实体编造和结构不稳定。

## 5. 家庭声音故事书（成人线）

### 5.1 3-8 幕互动阅读

故事按 3-8 幕组织，带分支与多个结局。阅读器提供进度、返回、重读、方言词注释、普通话辅助文本与语音示例。故事可以短到 3 幕，也可以展开到 8 幕，适配手机阅读和现场演示。

代表内容：

- 正经模式：《月光光》《老鼠娶亲》《阿婆的艇仔粥》《龙舟饭》《年廿八，洗邋遢》
- 鬼故事模式：《井边的鹰爪兰》《仙湖里的金花》《龙宫煮泉》
- 野史模式：《状元及第粥》《陈梦吉的扭计》《珠玑巷的夜》

### 5.2 方言原文、普通话与词语注释

每幕同时提供粤语叙述、普通话辅助文本和方言词解释。用户点击词语即可查看含义及简短文化说明，例如“地堂”不仅是“天井”，还与西关大屋的生活场景有关。

### 5.3 语音示例与真实录音

- 故事页提供浏览器语音合成示例，并明确标注为合成，不是长辈真人录音。
- `/record` 提供本机录音棚：浏览器录音、可选的浏览器自动转写、逐句校对、试听与删除。
- `/archive` 管理声音档案：查看、试听、转写、导出与导入。
- 录音默认只存在本机 IndexedDB，不上传服务器；单段上限 8 MB，总上限 80 MB。
- 家庭任务包可把一次家庭共读变成可执行的小任务，降低“不知道怎么开始录”的门槛。

### 5.4 三种叙事模式

同一素材库按 `heritage`、`ghost`、`wild_history` 标记适用范围，生成时注入不同语气和内容边界。鬼故事不血腥、不宣扬迷信；野史明确标注“据传 / 野史”，不冒充正史。

### 5.5 声音地图与故事卡

- 地图是故事导航示意图，不是精准地理数据；同坐标故事合并为一个节点，展开后逐项选择。
- 阅读完成后可生成并下载 PNG 声音故事卡，把标题、方言信息和代表性语句变成便于转发的内容。

### 5.6 可追溯的资料库

`/library` 现有 164 条素材，覆盖童谣、传说、民俗、饮食、歇后语、农谚、谜语和绕口令等类型，按 29 个内容文件组织。每条素材尽可能记录来源、授权状态、地区、主题、方言词和适用模式；支持搜索、类型 / 地区 / 模式筛选、详情查看与导出。

### 5.7 AI 工坊与预生成演示

在服务端环境，用户可在 `/studio` 选择素材、模式与幕数，由模型生成 3-8 幕结构、普通话翻译、方言词注释、实体和选择分支，再运行自动检查。`/demo` 保存三种模式的真实模型预生成结果，打开即看，不依赖现场生成速度。

### 5.8 三语、移动与离线

- **简 / 繁 / 英**：同一路由切换；28 个故事与儿童学习内容有完整英文覆盖，繁体由 opencc 统一转换。
- **PWA**：提供 manifest、Service Worker 与安装提示，可把站点装到手机主屏；已打开过的页面和封面离线可看。
- **学习播放**：示例语音支持慢速 / 标准 / 原速；翻译可收起为「点开普通话翻译」，方便先听后看；词卡可逐词发音。
- **找故事**：故事馆支持关键词搜索、年龄筛选、收藏与继续阅读，全部本机保存。
- **分享**：故事页调用系统分享，失败时复制链接；结局仍可下载声音故事卡。

## 6. 儿童粤语启蒙（儿童线）

### 6.1 独立儿童池

- 17 个儿童故事，4-6 岁 9 个、6-9 岁 8 个，全部避开鬼故事、野史和开放式 AI 生成。
- 2026-11-20 新增的 5 个适龄故事（《氹氹转，菊花圆》《点虫虫》《排排坐，食粉果》《落雨大，水浸街》《年廿八，洗邋遢》）均为 5 幕、2 个结局，并配套 900×675 封面。
- 香港内容包新增《天星小轮过海》《叮叮车上的旧车票》《茶餐厅的菠萝油》，全部为原创虚构故事，含粤语原文、普通话 / 英文翻译、词卡与小测。

### 6.2 学习闭环

一个儿童故事可以完整走完：

1. **听**：逐幕粤语原文、普通话 / 英文辅助、语音示例；示例语音可选慢速 / 标准 / 原速。
2. **跟读**：每幕「跟读一次」，录音、回放、重录；练习录音不写入声音档案。
3. **认词**：每幕词卡，点开看意思和例句，可逐词听粤语发音，可标记「已认识」。
4. **小测**：读完后 3 道理解题，答错给提示，可重选，不扣分、不排名。
5. **小结**：统计读了几幕、跟读几段、认识几个词、答对几题。

阅读器还提供「收起翻译 / 点开普通话翻译」，让孩子先听粤语原文，再决定是否看辅助文本。

### 6.3 家长视角

- 家长页集中展示每个故事的学习记录，可单个清除或全部清除。
- 学习进度只存本机，不上传、不做账号。
- 清除学习记录不会删除录音；录音仍在声音档案中单独管理。
- 儿童模式通过 6+7 的家长门退出，避免孩子误入成人内容。

### 6.4 儿童内容边界

- 不出现鬼故事、野史、开放生成和排行榜。
- 不录音也能完成阅读和测验，录音始终是可选增强。
- 词卡必须来自故事原文或词注；小测只考故事内容。
- 所有儿童故事都通过内容校验：至少 3 个关键词、3 道小测、封面齐全、场景引用无悬空。

## 7. 推荐体验路径

### 路径 A：第一次了解声迹（成人线）

1. 打开首页，进入 `/stories/moonlight`。
2. 点击“地堂”等方言词，查看含义与注释。
3. 做一个剧情选择，读到结局。
4. 打开 `/record` 或 `/archive`，看本机录音与声音档案。
5. 读完生成声音故事卡。

### 路径 B：看儿童学习闭环

1. 从首页进入 `/kids`，选择 4-6 岁或 6-9 岁故事。
2. 打开《天星小轮过海》，阅读第一幕；试试慢速朗读与「收起翻译」。
3. 点「跟读一次」，录一段并回放（也可以跳过）。
4. 点开词卡，点一下发音，标记「我认识这个词」。
5. 读到结局，做 3 道小测，看学习小结。
6. 到 `/kids/parent` 查看记录并尝试清除。

### 路径 C：查看内容生产链路

1. 打开 `/library`，搜索“五羊”或按“鬼故事模式”筛选。
2. 查看素材摘要、方言词、来源和授权状态。
3. 在服务端环境打开 `/studio`，选择素材、模式与幕数并生成。
4. 查看 3-8 幕结构、翻译、注释和 8 项自动检查结果。
5. 若只有静态在线环境，直接打开 `/demo` 查看预生成结果。

## 9. AI 输出如何验收

声迹把黄金样品作为内容生成的回归标尺。当前共有 8 个黄金样品：正经模式 6 个、鬼故事模式 1 个、野史模式 1 个。

生成支持 3-8 幕、4 种叙事骨架（straight、early_split、late_split、double_fork）与 seed 可复现。每次生成运行以下 8 项自动检查：

| 检查项 | 目的 |
|---|---|
| `json_schema_valid` | 必要字段和整体结构存在 |
| `act_count 3-8` | 幕数在 3-8 之间 |
| `plan_matches` | 输出符合预先声明的幕数与分支计划 |
| `ending_scene_present` | 存在收束结局，且结局不再包含选择 |
| `glossary_terms_present` | 覆盖黄金样品要求的方言词 |
| `translation_present` | 存在普通话翻译 |
| `entities_are_grounded` | 实体能在素材或黄金样品预期中找到依据 |
| `choices_present` | 非结局场景均提供选择 |

**正确解读**：这说明既定样品和规则上的结构、覆盖与实体约束通过，不等于所有新素材都永远不会出错，也不能替代人工事实核查、版权审查和语言润色。

## 11. 产品差异

1. **双入口共用一套内容底座**：成人故事书与儿童启蒙不是两个产品，共享素材、故事引擎和录音能力。
2. **地方素材有来源**：资料库保留来源、授权状态和待研究标记。
3. **同一素材三种讲法**：一套内容覆盖家庭、悬疑和民间趣闻场景。
4. **儿童学习有闭环**：不是只加儿童皮肤，而是听、跟读、认词、小测、小结五步。
5. **生成结果有验收**：黄金样品把“看起来不错”转化为可重复运行的 8 项结构检查。
6. **录音不出本机**：录音、转写与学习进度默认都保存在浏览器本机，可删除、可导出。
7. **隐私优先**：无需注册、无账号体系；无广告、无第三方统计，不建立用户画像；自动转写可关闭，AI 工坊只发送素材文本。

## 12. 内容、版权与隐私原则

- 传统童谣和民间故事以公有领域素材为起点，但具体整理、录音和图片仍可能有独立版权，正式使用前需继续复核。
- 政府或公开网页中的事实进行提炼和改写，不直接复制长段受保护文本。
- 参考类条目只作研究线索，需要补充正文或授权时不伪装成完整素材。
- 鬼故事不血腥、不低俗、不宣扬迷信；野史明确标注“据传 / 野史”。
- AI 生成文本和合成语音应明确标注，不冒充真实人物表达。
- 录音只存本机；自动转写由浏览器语音服务处理，页面明确提示，可在录音棚关闭。
- 无需注册、无广告、无第三方统计脚本；不建立用户画像，也不做跨站追踪。
- 儿童模式不出现广告、排行榜和开放式生成；家长可清除学习记录。
- 当前示意地图不作为精确地理位置或田野调查证据。

## 14. 可直接复制的产品介绍

### 14.1 50 字版

声迹把粤语童谣、传说和家庭故事变成 3-8 幕互动书，也给孩子一条听、跟读、认词、小测的粤语启蒙路径。

### 14.2 150 字版

VoiceTrace「声迹」是一款双入口方言故事书。成人可以读 3-8 幕互动故事、查方言词、录下自家的粤语版本；4-9 岁孩子可以在独立儿童池里听故事、逐幕跟读、认词、做 3 道小测，家长查看学习小结。产品现有 28 个故事、164 条有来源的粤语素材、17 个儿童故事和 8 个黄金样品，支持简 / 繁 / 英与离线安装；无需注册，录音与学习进度默认只存本机，无广告与第三方统计。

### 14.3 评委版完整介绍

声迹关注的不是方言能否被机器识别，而是一个家庭的故事如何被下一代听懂、参与并继续讲下去。成人入口是一条家庭声音故事书：28 个 3-8 幕互动故事、三种叙事模式、方言注释、普通话辅助、本机录音、声音档案和家庭任务包。儿童入口是一条粤语启蒙闭环：17 个独立适龄故事，听、跟读、认词、小测、小结五步，录音可选，学习进度只存本机，家长可以查看和清除；香港内容包补上天星小轮、叮叮电车和茶餐厅。全站支持简 / 繁 / 英切换，并可安装到手机主屏离线阅读。产品无需注册、没有账号，也没有广告和第三方统计脚本。内容侧，项目整理了 164 条有来源与授权状态的粤语素材；生产侧，AI 工坊把素材转为 3-8 幕故事，并用 8 个黄金样品执行 8 项自动检查。声迹目前仍是参赛原型：真实亲子试用、真人录音和人工复核是下一阶段工作，脚本自测与模拟报告不会被当作用户证据。
