# 候选 02 · 账单差异排查

> 状态：未选中，保留备选（2026-11-15 决策）  
> 赛道：商业增长；可兼报行业服务  
> 目标奖项：效率革新奖、商业价值奖  
> 一句话：上传两套账单，3 分钟定位每一笔差异的原因和责任人。

## 1. 用户与痛点

**用户**：

- 电商商家（微信/支付宝/抖音/拼多多/ERP 对账）；
- SaaS/订阅制公司（支付网关 vs 内部订单）；
- 支付服务商/代运营/财务外包。

**痛点**：

- 订单、支付、退款、手续费、结算周期、时区、重复支付，任何一项对不上都要人工翻几十页 Excel；
- 财务只知道“总数对不上”，不知道“哪几笔、为什么、谁负责”；
- 月底对账熬夜，差异原因靠猜；
- 对账 SaaS 偏大客户，接入周期长，小商家用不起。

## 2. 解决方案

**核心闭环**：

1. 上传两套 CSV/Excel（渠道账单 vs 内部订单）。
2. 自动识别字段、统一时区/币种/金额口径。
3. 匹配订单号/金额/时间，分类差异：时间差、手续费、退款、重复、漏单、金额不符。
4. 对每类差异给出原因解释 + 证据 + 建议动作（补单/调账/联系渠道）。
5. 导出差异报告 + 调账明细。

**产品形态**：Web 应用；后续可接微信/支付宝/抖音开放平台 API。

## 3. 差异化

| 维度 | 现有方案 | 我们 |
|---|---|---|
| 定位 | 对账工具 | 差异原因解释器 |
| 输入 | 固定格式/API | 任意 CSV/Excel，自动识别字段 |
| 输出 | 差额数字 | 原因、证据、责任人、调账建议 |
| 用户 | 大客户/财务 | 中小商家/代运营/财务外包 |
| 体验 | 配置重、周期长 | 上传即用、3 分钟出结果 |

**一句话差异**：不是“告诉你差多少”，而是“告诉你为什么差、该找谁、怎么调”。

## 4. 竞品

| 竞品 | 类型 | 弱点 |
|---|---|---|
| 微信/支付宝后台 | 渠道账单 | 只给流水，不比对内部订单 |
| ERP/财务软件 | 对账模块 | 配置重、不灵活、不解释 |
| 对账 SaaS | 专业工具 | 偏大客户、按交易量收费、接入周期长 |
| Excel VLOOKUP | 手工 | 易错、无法解释、不可复用 |
| 通用 AI | 聊天 | 可以解释，但不能稳定匹配/调账 |

## 5. MVP 范围（8 天）

- 支持 1 个渠道：微信支付账单 + 1 种内部订单 CSV。
- 5 类差异：时间差、手续费、退款、重复、漏单。
- 1 份差异报告 + 调账明细 CSV。
- 示例账单一键体验（评委无需上传）。
- 基础项目管理、空状态、错误处理、隐私说明。

## 6. 8 天可行性

| 天数 | 任务 | 风险 |
|---|---|---|
| Day 1 | 找 3 个商家/财务，拿 2 份脱敏账单 | 账单难拿 |
| Day 2 | CSV 解析 + 字段映射 + 匹配 | 格式多样 |
| Day 3 | 差异分类 + 原因解释 | 规则复杂 |
| Day 4 | 报告 + 调账建议 | 财务口径 |
| Day 5 | 完整度/体验/隐私 | 数据敏感 |
| Day 6 | 部署 + 示例账单 | 脱敏 |
| Day 7 | 用户测试 | 信任 |
| Day 8-9 | 提交材料 | 材料遗漏 |

**结论**：技术可行，最大风险是拿不到真实账单；如果只有模拟数据，价值证明会弱很多。

## 7. 风险与应对

| 风险 | 应对 |
|---|---|
| 真实账单难拿 | 用公开样本/模拟数据；找朋友商家脱敏；签署保密说明 |
| 数据敏感 | 本地处理/加密存储/不持久化；隐私说明 |
| 竞品多 | 靠“原因解释 + 调账建议 + 中文渠道”差异化 |
| 财务口径复杂 | 先做 5 类高频差异；其余标记“人工复核” |
| 付费意愿 | 按次/按月；先验证 3 个用户愿意付 |
| 平台规则 | 不抓取平台数据；只处理用户上传的账单 |

## 8. 评委契合

- 商业增长：直接省钱/省时间，ROI 清晰。
- 效率革新奖：月底对账从 2 天降到 2 小时。
- 商业价值奖：中小商家/代运营有明确付费意愿。
- 演示冲击：数字对比强（“1,284 笔差异，37 笔真问题，追回 8,600 元”）。

## 9. 证据计划

- [ ] 3 个商家/财务访谈记录。
- [ ] 2 份脱敏账单 + 差异报告。
- [ ] 使用前后时间对比（如 2 天 → 2 小时）。
- [ ] 追回金额/减少差错的具体案例。
- [ ] 1-2 条用户评价/付费意向。
- [ ] TRAE Session ID、截图、部署截图。
