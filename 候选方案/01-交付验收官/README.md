# 候选 01 · 交付验收官

> 状态：未选中，保留备选（2026-11-15 决策）  
> 赛道：行业服务 / 客户交付产品；可兼报商业增长  
> 目标奖项：效率革新奖、商业价值奖、值得一赏奖  
> 一句话：把合同/SOW 变成可执行的验收清单，自动跑一遍，生成客户敢签、你能收尾款的验收报告。

## 1. 用户与痛点

**用户**：

- 软件外包公司/工作室的项目经理、交付负责人；
- 自由职业开发者、独立开发者；
- 甲方（企业/政府/学校）的项目负责人、采购/信息化部门。

**痛点**：

- 合同写“功能完整、运行稳定”，验收时变成“按钮颜色不对”；
- 需求文档、原型、代码、部署环境、账号权限散落各处，没人能证明“交付了什么”；
- 甲方怕付钱拿不到东西，乙方怕干完收不到尾款；
- 验收标准不清晰，导致无限改稿、尾款拖欠、甚至诉讼。

**痛点的现实证据**：

- 中国软件外包市场规模约 6,165.98 亿元（2026 年估算），服务外包执行额持续增长（商务部数据）。
- 软件开发合同纠纷中，“是否完成交付/验收”是核心争议；法院案例中常见“甲方称未验收、乙方称已交付”。
- 自由职业者/外包团队普遍采用“三三四/四三三”付款，但验收标准仍靠口头/Excel。

## 2. 解决方案

**核心闭环**：

1. 上传合同/SOW/需求文档 → AI 抽取交付物、验收标准、边界、付款节点。
2. 生成验收清单（功能/内容/性能/安全/文档/部署/权限/培训），每项带检查方法。
3. 输入体验链接/测试账号 → 自动检查：可访问、关键页面、移动端、性能、死链、安全头、隐私政策。
4. 人工确认 + 上传证据（截图/日志/录屏），形成证据链。
5. 生成验收报告 PDF：结论、风险项、整改建议、签字页。
6. 生成“遗留问题清单”和“交付说明”，减少扯皮。

**产品形态**：Web 应用（桌面 + 移动端适配），后续可做浏览器插件/飞书机器人。

## 3. 差异化

| 维度 | 现有方案 | 我们 |
|---|---|---|
| 起点 | Excel/Word 模板 | 从合同/SOW 自动生成 |
| 过程 | 人工勾选 | 自动检查 + 人工确认 + 证据 |
| 终点 | 一份文档 | 可分享/可签字的验收报告 + 证据链 |
| 场景 | 通用项目管理 | 中文软件交付、甲方/乙方双端 |
| 责任 | 口头/聊天记录 | 时间戳、截图、版本、审计留痕 |

**一句话差异**：不是“又一个测试工具”，而是“验收这件事的端到端产品”。

## 4. 竞品

| 竞品 | 类型 | 弱点 |
|---|---|---|
| MilestoneProof | 海外 hackathon 项目 | 偏代码审查、无中文场景、无完整验收报告 |
| WPS AI 验收报告 | 文档生成 | 只生成报告，不做实际检查/取证 |
| 禅道/ONES/Jira | 项目管理 | 管任务，不管验收证据 |
| TestRail/测试平台 | 测试管理 | 管用例，不管合同/SOW |
| 通用 AI | 聊天 | 能写清单，不能跑检查、不能留证据、不能出报告 |
| 律师/仲裁 | 事后救济 | 贵、慢、伤关系 |

## 5. MVP 范围（8 天）

- 支持 1 种项目类型：企业官网/管理后台（登录、列表、表单、导出）。
- 输入：PDF/Word SOW + 公开体验链接 + 测试账号。
- 输出：15-20 项清单、5-8 项自动检查、1 份 PDF 报告、1 个分享链接。
- 示例项目一键体验，评委无需上传。
- 基础项目管理、空状态、错误处理、移动端适配、隐私说明。

## 6. 8 天可行性

| 天数 | 任务 | 风险 |
|---|---|---|
| Day 1 | 方向验证、3 个访谈、项目骨架 | 访谈不足 |
| Day 2 | 文档解析 + 清单生成 | 解析不准 |
| Day 3 | 自动检查 + 证据 | Playwright 不稳定 |
| Day 4 | 报告 + PDF 导出 | 排版耗时 |
| Day 5 | 完整度/体验/合规 | 范围蔓延 |
| Day 6 | 部署 + 示例数据 | 部署/访问 |
| Day 7 | 用户测试 + 修复 | 找不到用户 |
| Day 8-9 | 提交材料 + 视频 + 提交 | 材料遗漏 |

**结论**：可行，但必须严格冻结范围；Day 3 结束还没跑通就砍自动检查项。

## 7. 风险与应对

| 风险 | 应对 |
|---|---|
| 评委觉得偏 B 端 | 用“尾款拖 6 个月”故事开场；演示消费级体验 |
| 自动检查覆盖不足 | 明确“AI 检查 + 人工确认”；不承诺全自动 |
| 合同解析不准 | 先支持结构化模板；人工修正；标注置信度 |
| 法律责任 | 定位辅助工具；报告注明“不构成法律意见” |
| 真实项目难找 | 用自己/朋友脱敏项目；找 3 个自由职业者试用 |
| 竞品跟进 | 建立验收模板库 + 证据链 + 中文合规 checklist 作为壁垒 |

## 8. 评委契合

- 行业服务 / 客户交付产品：完美匹配。
- 商业增长：能算清“减少尾款纠纷/缩短验收周期”的 ROI。
- 效率革新奖：验收准备从 6 小时降到 40 分钟。
- 商业价值奖：外包公司/自由职业者愿意按项目付费。
- 造物故事奖：真实接单故事 + 产品化过程。

## 9. 证据计划

- [ ] 3-5 个自由职业者/外包公司访谈记录。
- [ ] 1 个真实项目的脱敏 SOW + 验收报告。
- [ ] 使用前后时间对比（如 6 小时 → 40 分钟）。
- [ ] 1-2 条用户原话评价。
- [ ] 付费意向（如“愿意付 99 元/项目”）。
- [ ] TRAE Session ID、关键对话截图、部署截图。
