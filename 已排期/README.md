1. 从 `候选方案/` 中选定一个方向后，将该方案文件夹整体移动到本目录，保留原序号和名称。
2. 在本目录的 `README.md` 中登记：方案名、选定日期、目标赛事、负责人、关键里程碑。
3. 同步更新根目录 `README.md` 的“变更记录”和 `docs/contest/05-8天执行计划.md` 的方向假设。
4. 已排期方案的所有后续改动（功能、范围、时间）先登记到 `docs/contest/05-8天执行计划.md`，再动代码。
