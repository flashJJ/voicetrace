# 已排期 03 · 声迹 · 方言故事书

> 状态：已排期（2026-11-15 选定）  
> 目标赛事：TRAE 好应用大赏赛（报名截止 2026-11-23）  
> 赛道：游戏娱乐（可兼报学习生活/文化传播）  
> 目标奖项：乐在其中奖、造物故事奖、值得一赏奖  
> 一句话：把爷爷奶奶讲的故事，变成可以玩的方言互动书。
>
> 最新进度：资料库 91 条（拆成 23 个分类文件）+ 3 种模式 + 9 个互动故事 + 8 个黄金样品；AI 工坊 `/studio` 已跑通 Mock 验收。

## 1. 为什么选这个方向

用户在 2026-11-15 的决策中选择“非遗/方言叙事”，且暂时没有 B 端用户资源。这个方向商业分不如交付验收官，但在当前约束下有三个优势：

1. **不依赖外部客户**：可以先用公开资料库素材（91 条）做出 9 个互动故事（正经/鬼故事/野史）；真实录音为可选加分项。
2. **情绪价值强**：方言、长辈声音、家族记忆，天然适合“造物故事奖”和官方传播。
3. **8 天可交付**：核心是资料库 + 翻译/分幕 + 3 幕互动 + 分享卡，不需要复杂后端。

> 风险：赛道里有“乡音计划·读侨批”“瓯小鹿”“瓷都小匠”等竞品，必须做出明确差异，不能做成“方言翻译器”或“又一个 AI 故事生成器”。

## 2. 用户与痛点

**核心用户**：

- 18-35 岁离开家乡的年轻人：想保存长辈的声音/故事，但不知道怎么做；
- 家庭：祖辈与孙辈有语言隔阂，想让老人讲故事、孩子听得懂；
- 学校/社区文化教育者：想做方言/地方文化课堂；
- 地方文旅/非遗机构：想做可参与、可分享的内容（第二阶段）。

**痛点**：

- 老人声音和方言故事没有被保存，等到想记录时可能已经来不及；
- 现有方言产品多是“翻译/朗读/识别”工具，缺少“可参与、可分享”的情感体验；
- 年轻人听不懂方言，长辈的故事传不下去；
- 非遗/地方文化内容同质化，缺一个“跟我有关”的入口。

**一句话场景**：

> 外婆用方言讲了一个小时候的故事。我想把它留下来，但方言听不懂、文字没味道、视频不会剪。声迹把它变成一本可以点、可以听、可以分享的方言互动书。

## 3. 解决方案

**核心闭环**：

1. **选素材**：从资料库选一段方言故事/童谣；可选上传长辈录音。
2. **听懂它**：AI 转写 + 普通话翻译 + 方言词注释（glossary）。
3. **变成书**：生成 3 幕互动故事，每幕 2-3 个选择；用户可听原声、看字幕、点词注释。
4. **分享它**：生成“声音故事卡”（海报/15 秒视频），发给家人朋友。
5. **留住它**：故事钉在地图上，形成家庭/社区/地方的“声音地图”。

**产品原则**：

- **真实素材优先**：资料库文本/读音为底，真实录音是加分项；AI 只做转写、翻译、辅助朗读；AI 合成音必须标注。
- **不替代人**：不生成虚构的“长辈故事”，只整理用户提供的真实素材。
- **可撤回**：录音（可选）/故事可随时删除，分享前需本人同意。
- **轻游戏**：互动是“翻页 + 选择 + 听声音”，不做复杂游戏引擎。

## 4. 差异化

| 维度 | 乡音计划·读侨批 | 瓯小鹿 | 瓷都小匠 | 猫箱/星野 | 声迹 |
|---|---|---|---|---|---|
| 核心 | 用你的声音读侨批 | 温州话翻译/朗读/对话 | 景德镇官方文化小游戏 | 通用 AI 角色故事 | 家庭真实故事 → 互动书 |
| 素材 | 历史侨批 | 用户输入 | 官方非遗内容 | AI 生成 | 公开素材/可选录音 |
| 交互 | 朗读 + 声音卡 | 工具型 | 游戏化科普 | 聊天 | 3 幕选择 + 原声 + 注释 |
| 传播 | 声音卡 | 工具分享 | 小游戏 | 角色分享 | 故事卡 + 声音地图 |
| 差异 | 机构/历史 | 方言工具 | 官方/大制作 | 通用娱乐 | 个人/家庭记忆，UGC，地图 |

**一句话差异**：

> 乡音计划保存的是一封历史信件，声迹保存的是你家饭桌上那个还没讲完的故事。

## 6. MVP 范围（8 天）

### 必须做

- [ ] 1 种方言（优先你/家人会说的；若没有，选粤语/四川话，CosyVoice 支持较好）。
- [ ] 3 个种子故事：2 个公有领域童谣/民间故事 + 1 个真实家庭故事（需授权）。
- [ ] 从资料库选 3 条素材；可选录音上传（手机浏览器可用）。
- [ ] ASR 转写 + 普通话翻译 + 方言词注释（每篇 3-5 个词）。
- [ ] 3 幕互动故事（每幕 2-3 个选择，2 个结局）。
- [ ] 原声播放 + 字幕 + 注释点击。
- [ ] 声音故事卡（PNG 海报；视频为加分项）。
- [ ] 故事地图（3 个 pin）。
- [ ] 示例故事一键体验（评委无需录音）。
- [ ] 授权/隐私说明、删除功能、AI 合成标注。

### 可以做

- [ ] 15 秒分享视频（Remotion/FFmpeg）。
- [ ] 家庭协作（邀请家人补充故事/照片）。
- [ ] 故事册导出 PDF。
- [ ] 方言小词典/文化注释卡。
- [ ] 简单用户体系（邮箱/微信登录）。

### 不做

- 不做方言翻译器/词典大全。
- 不做通用 AI 故事生成器。
- 不做复杂游戏引擎/3D/AR。
- 不做多方言大规模采集。
- 不做机构后台/内容审核系统。
- 不做硬件/线下装置。

## 7. 内容与素材策略（无人工录入版）

| 素材 | 来源 | 授权/合规 | 备注 |
|---|---|---|---|
| 童谣/传说/民俗文本 | 粤语故事资料库（91 条） | 逐条标注 `traditional-public-domain` / `government-fact` / `reference` | 已含来源链接；不直接抓取官方语料 |
| 语音示例 | 浏览器语音/TTS | 标注 AI 合成/示例 | 真实录音为可选加分项，不是前置条件 |
| 方言 TTS | CosyVoice2/3、阿里云百炼等 | 遵守模型/平台条款；标注 AI 合成 | 仅用于示例/辅助 |
| 图片/插画 | 自己拍摄/可商用素材/AI 生成 | 保留授权记录 | 避免未授权老照片 |
| 地图 | MapLibre/Leaflet + OpenStreetMap | 遵守 OSM attribution | 不用受限地图数据 |
| 方言语料 | 中国语言资源保护工程等 | **不直接抓取/商用**；仅参考 | 需要授权才能使用 |

**内容生产流程**：

1. 从资料库选 3 条：`yue-rhyme-moonlight`、`yue-legend-five-goats`、`yue-proverb-polo-chicken`。
2. 用 LLM 生成：粤语原文 → 普通话翻译 + 方言词注释 + 三幕结构。
3. 对照 `golden-samples.json` 校验：三幕数、实体、注释、翻译、是否幻觉。
4. 用浏览器语音/TTS 生成示例音（标注 AI）；真实录音可选。
5. 做故事卡：一句金句 + 一张图 + 二维码/链接。
6. 用 `/library` 页面继续扩充素材；缺正文的篇目标 `needsResearch`。

## 9. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 没有真实用户 | 高 | 中 | 用家人/朋友做 10 人测试；如实说明“早期测试” |
| 方言 TTS 不准 | 中 | 高 | 资料库文本为主；TTS 只做示例；真实录音可选 |
| 素材版权/授权 | 中 | 高 | 公开素材 + 来源标注；不用未授权音频/老照片 |
| 情感/隐私 | 中 | 高 | 分享前本人同意；可删除；不公开私密故事 |
| 同质化 | 高 | 中 | 强化“家庭真实故事 + 互动 + 地图”，不做翻译/通用故事 |
| 评委觉得“不够游戏” | 中 | 中 | 3 幕选择 + 2 结局 + 收集/地图；现场演示互动 |
| 音频加载慢 | 中 | 中 | 压缩音频；CDN；加载状态；离线兜底 |
| 内容太少 | 中 | 中 | 3 个种子故事 + 示例模式；后续 UGC |
| 最后一天改坏 | 中 | 高 | 11.22 冻结代码；11.23 只提交 |
